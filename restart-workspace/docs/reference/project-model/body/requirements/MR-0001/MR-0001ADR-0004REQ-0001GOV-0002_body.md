# MR-0001ADR-0004REQ-0001GOV-0002 — Copertura negativa dei valori controllati documentali

## Intento

Dimostrare che il controllo dei valori documentali non si limita a confermare i casi validi, ma intercetta esempi intenzionalmente errati relativi a value set, status contestuali, ruoli di label e frasi vietate.

## Obbligo di governance

Il checker dei valori controllati documentali deve eseguire fixture negative governate e deve fallire la verifica complessiva quando una fixture negativa passa oppure non produce l'errore atteso.

## Ambito

Incluso:

- value set mancanti;
- array tassonomici generici deprecati;
- valori privi di `meaning`;
- ruoli di label non registrati;
- status usati nel contesto sbagliato;
- frasi operative vietate usate fuori dal vocabolario che le dichiara.

Escluso:

- validazione completa del modello lessicale dei termini, che restera responsabilita di un futuro controllo del vocabolario controllato;
- validazione semantica libera dei testi narrativi oltre alle frasi vietate dichiarate.

## Acceptance

Il requisito e soddisfatto quando:

- il checker esegue un registro governato di fixture negative;
- ogni fixture negativa e isolata in un workspace minimale;
- il checker invocato sulla fixture deve fallire;
- ogni fixture dichiara almeno una substring di errore attesa;
- il report e l'output CLI indicano quante fixture negative sono state verificate.

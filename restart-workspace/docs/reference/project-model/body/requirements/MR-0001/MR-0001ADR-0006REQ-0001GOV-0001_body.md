# MR-0001ADR-0006REQ-0001GOV-0001 — Produzione locale deterministica dell'handoff archive

## Intento

Garantire che l'handoff archive sia prodotto in modo locale, ripetibile e coerente con lo stato governato del repository.

## Obbligo di governance

Il tool di handoff deve:

- essere eseguito dal repository locale;
- usare `ThreatForge` come label visibile;
- non usare `Restart` come label utente;
- includere stato Git, log, registry snapshot e output del check locale;
- fallire in modalità non dry-run quando il working tree non è pulito, salvo opzione esplicita di override;
- dichiarare il requisito implementato tramite JSDoc.

## Ambito

Incluso:

- generazione archive;
- controllo working tree;
- contenuto di continuità;
- tracciabilità implementativa.

Escluso:

- validazione semantica completa dei contenuti inclusi;
- pubblicazione remota dell'archive.

## Acceptance

Il requisito è soddisfatto quando il tool è presente, tracciato, verificabile con `--dry-run` e produce localmente un archive deterministico dopo commit/push governato.

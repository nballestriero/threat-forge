# MR-0001ADR-0006REQ-0001 — Generatore locale di handoff archive

## Intento

Fornire un comando locale per produrre uno ZIP di handoff ThreatForge direttamente dal repository, evitando archive esterni non governati e permettendo a un LLM di rileggere il progetto per riprendere lo sviluppo.

## Obbligo funzionale

Il sistema deve fornire un tool locale che genera un handoff archive contenente almeno:

- stato Git corrente;
- ultimi commit;
- output del `restart-workspace` check;
- snapshot dei registry governati rilevanti;
- istruzioni di continuità per una nuova sessione;
- snapshot dei file tracciati da Git del progetto.

## Ambito

Incluso:

- generazione locale sotto `artifacts/handoff/`;
- contenuti testuali leggibili;
- archive `.zip` finale;
- supporto `--dry-run`;
- copia dei file tracciati da Git sotto `project-snapshot/`;
- manifest dello snapshot con conteggio file e regole di inclusione/esclusione.

Escluso:

- creazione di release GitHub;
- upload remoto dell'archive;
- modifica automatica del repository;
- inclusione di `.git`, dipendenze installate, cache, build output o artifact non tracciati.

## Acceptance

Il requisito è soddisfatto quando un comando locale può produrre un archive di handoff ThreatForge dal repository, includendo sia il contesto operativo sia lo snapshot dei file tracciati del progetto, e il tool è tracciato nel registro di implementation trace.

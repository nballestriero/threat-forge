# MR-0001ADR-0006REQ-0001 — Generatore locale di handoff archive

## Intento

Fornire un comando locale per produrre uno ZIP di handoff ThreatForge direttamente dal repository, evitando archive esterni non governati.

## Obbligo funzionale

Il sistema deve fornire un tool locale che genera un handoff archive contenente almeno:

- stato Git corrente;
- ultimi commit;
- output del `restart-workspace` check;
- snapshot dei registry governati rilevanti;
- istruzioni di continuità per una nuova sessione.

## Ambito

Incluso:

- generazione locale sotto `artifacts/handoff/`;
- contenuti testuali leggibili;
- archive `.zip` finale;
- supporto `--dry-run`.

Escluso:

- creazione di release GitHub;
- upload remoto dell'archive;
- modifica automatica del repository.

## Acceptance

Il requisito è soddisfatto quando un comando locale può produrre un archive di handoff ThreatForge dal repository e il tool è tracciato nel registro di implementation trace.

# MR-0001ADR-0005REQ-0002GOV-0002 — Copertura negativa del controllo degli header governati

## Intento

Il controllo degli header dei body governati deve dimostrare di intercettare errori reali, non solo di passare sul caso valido corrente.

## Regola specializzata

Il check deve eseguire fixture negative versionate per i casi minimi di divergenza tra registro e body Markdown. Ogni fixture negativa deve fallire e deve produrre almeno il diagnostico atteso dichiarato dalla fixture.

## Verifica

La verifica deve fallire quando una fixture negativa passa, quando il diagnostico atteso non e presente, o quando il set di fixture negative non e leggibile dal tool.

## Acceptance

Il requisito specializzato e soddisfatto quando il check degli header dei body governati esegue le fixture negative e riporta un conteggio deterministico delle fixture verificate senza warning o errori sul workspace valido.

# MR-0001ADR-0003REQ-0001GOV-0002 — Copertura negativa del controllo di tracciabilita implementativa

## Intento

Dimostrare che il controllo di tracciabilita implementativa intercetta esempi volutamente non validi, oltre a confermare il caso positivo del registro reale.

## Obbligo di governance

Il controllo della tracciabilita implementativa deve eseguire fixture negative governate e deve fallire la verifica quando una fixture non produce gli errori attesi.

## Ambito

Il requisito copre fixture per registro mancante o malformato, artifact id assenti o duplicati, status e artifact_type non supportati, requisiti collegati mancanti o sconosciuti e sorgenti senza dichiarazione JSDoc coerente.

## Acceptance

Il check passa solo quando tutte le fixture negative vengono eseguite, falliscono come previsto e producono i messaggi diagnostici attesi.

# MR-0007: Identity, user and access management

## Purpose

Definisce identità, utenti, ruoli, permessi e membership necessari alla piattaforma threat-forge.

## Scope

Include:

- utenti e identità;
- ruoli e permessi;
- project membership;
- ownership e accesso ai child projects;
- policy di autorizzazione per operazioni governate;

## Out of Scope

Non include:

- audit trail dettagliato;
- modello base threat analysis;
- STRIDE/STRIDE-AI;
- componenti UI generici oltre al consumo dei ruoli;

## Governance Notes

`MR-0007` è una macro-area funzionale distinta. Deve avere ADR, requisiti, grafo e implementazioni propri quando il lavoro operativo inizierà.

La sua presenza in questo micropasso definisce il confine documentale dell’area, non autorizza ancora implementazioni runtime o UI senza ADR e requisiti specifici.

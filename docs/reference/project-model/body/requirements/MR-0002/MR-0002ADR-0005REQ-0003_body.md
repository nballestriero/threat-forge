# MR-0002ADR-0005REQ-0003 — Editor VS Code guidato per MR, ADR e REQ

## Intento

Consentire l'authoring tecnico della documentazione governata da Visual Studio Code con suggerimenti, descrizioni e controlli immediati, senza modificare manualmente identificativi, relazioni o valori controllati.

## Obbligo funzionale

VS Code deve supportare file di richiesta governati e riconoscibili per la creazione o modifica guidata di:

- macro-requirement;
- ADR;
- requirement funzionali;
- requirement di governance.

Durante la compilazione VS Code deve:

- proporre soltanto campi e valori applicabili al tipo documentale selezionato;
- mostrare label e descrizione dei valori nei suggerimenti;
- mostrare la descrizione del campo o del valore tramite hover;
- segnalare valori non validi, relazioni incoerenti e campi obbligatori mancanti;
- proporre identificativi canonici esistenti quando il campo rappresenta una relazione;
- offrire task governati per preview e applicazione confermata;
- invocare il core condiviso senza duplicarne le regole.

## Ambito

L'editor opera sui file di richiesta e sui task governati. Non associa schemi di authoring direttamente ai registri canonici in modo da incoraggiarne la modifica manuale.

Il body Markdown rimane modificabile come contenuto discorsivo, ma i campi strutturati quali `status`, tipo e relazioni devono essere gestiti attraverso il record canonico o il flusso guidato.

## Acceptance

Il requisito e soddisfatto quando un autore puo:

- creare una richiesta MR, ADR o REQ;
- ottenere completamento per i valori controllati;
- leggere la descrizione di un valore nel completamento e tramite hover;
- ricevere diagnostica prima dell'esecuzione del tool;
- eseguire una preview senza side effect;
- applicare la creazione soltanto con conferma esplicita;
- ottenere record e body coerenti e verificati;
- aggiornare le proposte rigenerando le proiezioni dopo una modifica canonica.

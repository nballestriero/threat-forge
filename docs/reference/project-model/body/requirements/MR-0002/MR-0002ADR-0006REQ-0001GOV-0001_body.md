# MR-0002ADR-0006REQ-0001GOV-0001 — Canonical derivation and side-effect-free analysis

## Intent

Ensure that live Markdown assistance remains a deterministic projection of governed document models.

## Governance obligation

- The Markdown assistance core must derive section definitions from canonical body profiles.
- The Markdown assistance core must derive controlled suggestions from canonical value sets.
- The Markdown assistance core must use canonical stable rule identifiers for diagnostics.
- The Markdown assistance core must not write to the document, registry or repository.
- The Markdown assistance core must not silently normalize invalid authored content.
- A consumer must not inject independent canonical rules into the analysis request.

## Verification obligations

- The verification must compare completion results with the applicable canonical profile.
- The verification must compare diagnostic rule identifiers with the canonical rule catalog.
- The verification must confirm that repeated analysis of identical input returns equivalent ordered results.
- The verification must confirm that analysis does not modify input files.
- The verification must cover valid and invalid examples for every supported body model.

## Failure conditions

- The verification must fail when a completion contains an unknown canonical section.
- The verification must fail when a controlled suggestion is not present in its canonical value set.
- The verification must fail when analysis modifies a document or registry.
- The verification must fail when identical input produces different semantic results.

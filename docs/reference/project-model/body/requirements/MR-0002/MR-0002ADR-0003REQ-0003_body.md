# MR-0002ADR-0003REQ-0003 — Promozione governata di un artefatto pianificato materializzato

## Intent

Permettere che un artefatto non sorgente registrato come pianificato
venga dichiarato implementato soltanto dopo che il file materializzato
esiste e la verifica governata associata ha avuto esito positivo.

## Functional obligation

- ThreatForge must select exactly one planned implementation artifact by its registered artifact identifier.
- ThreatForge must require the planned artifact file to exist at the registered repository-relative path.
- ThreatForge must execute the registered governed verification command before changing lifecycle state.
- ThreatForge must replace planned status and planned path with implemented status and implemented path.
- ThreatForge must preserve the artifact identifier linked Requirements artifact type and repository path.
- ThreatForge must leave the artifact and implementation trace registry unchanged when verification fails.
- ThreatForge must require explicit confirmation before applying the lifecycle transition.
- ThreatForge must not modify the materialized artifact content during lifecycle promotion.
- ThreatForge must not perform commit or push operations.

## Scope

- Includes: planned non-source implementation artifacts whose registered file has been materialized
- Includes: deterministic verification of the registered artifact
- Includes: atomic implementation trace lifecycle transition
- Excludes: source scaffold promotion
- Excludes: artifact content generation or modification
- Excludes: autonomous commit or push operations

## Acceptance

- The requirement is accepted when one existing planned artifact is promoted only after its registered verification succeeds.
- The requirement is accepted when the final trace record declares implemented status and implemented path.
- The requirement is accepted when the promoted file path linked Requirements artifact type and artifact identifier remain unchanged.
- The requirement is accepted when failed verification leaves the artifact file and implementation trace registry unchanged.
- The requirement is accepted when the complete repository gate passes after the lifecycle transition.

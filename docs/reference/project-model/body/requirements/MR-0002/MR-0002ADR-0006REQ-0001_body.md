# MR-0002ADR-0006REQ-0001 — Contextual analysis of governed Markdown bodies

## Intent

Provide deterministic assistance from the current unsaved state of a governed Markdown body.

## Functional obligation

- The Markdown assistance core must accept the repository-relative document path.
- The Markdown assistance core must accept the current unsaved Markdown text.
- The Markdown assistance core must accept the current cursor position.
- The Markdown assistance core must identify the applicable logical document model.
- The Markdown assistance core must identify the applicable Markdown body profile.
- The Markdown assistance core must return applicable completion items.
- The Markdown assistance core must return deterministic diagnostics.
- The Markdown assistance core must return applicable hover information.
- The Markdown assistance core must return applicable quick fixes.
- The Markdown assistance core must prioritize the next missing required section.
- The Markdown assistance core must not propose a section that is already present at its maximum cardinality.
- The Markdown assistance core must propose only controlled values applicable to the current section.

## Scope

- Includes: Macro-requirement Markdown bodies
- Includes: ADR Markdown bodies
- Includes: Functional Requirement Markdown bodies
- Includes: Governance Requirement Markdown bodies
- Includes: unsaved editor text
- Excludes: direct repository mutations

## Acceptance

- The requirement is accepted when typing `##` returns the next missing required section with highest priority.
- The requirement is accepted when a completed required section is removed from applicable suggestions.
- The requirement is accepted when `Draft.` produces an invalid controlled value diagnostic.
- The requirement is accepted when duplicate and out-of-order sections produce stable diagnostics.
- The requirement is accepted when analysis leaves the document and repository unchanged.

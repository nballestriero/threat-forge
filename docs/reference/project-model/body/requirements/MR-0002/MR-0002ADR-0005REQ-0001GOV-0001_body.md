# MR-0002ADR-0005REQ-0001GOV-0001 — Wrapper sottili, naming canonico e dry-run sicuro

## Intent

Garantire che l'integrazione VS Code resti un punto di accesso sicuro e non diventi una seconda implementazione delle regole operative ThreatForge.

## Governance obligation

- The governed implementation must enforce this condition: usare esattamente label visibili con prefisso `ThreatForge:`.
- The governed implementation must enforce this condition: invocare i tool CLI esistenti tramite argomenti espliciti.
- The governed implementation must enforce this condition: usare la root del repository come directory di lavoro.
- The governed implementation must enforce this condition: mantenere `--dry-run` nei task che preparano documenti o handoff.
- The governed implementation must enforce this condition: non contenere logica di validazione, generazione o packaging duplicata.
- The governed implementation must enforce this condition: essere tracciati nel registro di implementation trace.

## Verification obligations

- The verification must confirm this condition: naming delle label.
- The verification must confirm this condition: mapping task-comando.
- The verification must confirm this condition: directory di lavoro.
- The verification must confirm this condition: modalità dry-run.
- The verification must confirm this condition: tracciabilità dell'artefatto editor.
- The verification must confirm this condition: validazione autonoma dei task tramite un nuovo checker.
- The verification must confirm this condition: modifica dei tool CLI esistenti.
- The verification must confirm this condition: automazione di commit o push dall'editor.
- The verification must confirm this condition: Il requisito è soddisfatto quando il catalogo contiene solo wrapper dei comandi governati, usa le label canoniche previste e non esegue scritture nei task di authoring o handoff.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

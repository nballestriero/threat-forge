# MR-0002ADR-0003REQ-0002GOV-0001 — Promozione verificata, atomica e non distruttiva

## Intento

Impedire che un file incompleto, non verificato o non coerente con il relativo record venga dichiarato come implementato.

## Obbligo di governance

La capacità deve:

- richiedere la conferma esatta `promote`;
- operare su un solo artifact ID esistente e nello stato `scaffolded`;
- richiedere `scaffolded_path`, file esistente e tracciabilità coerente con i requisiti collegati;
- richiedere `@derivedFromDecision`, `@macroRequirement` e una sola dichiarazione `@implementationStatus scaffolded`;
- rifiutare lo specifico placeholder `TODO: implement the governed ... behavior.` generato dallo scaffolder;
- richiedere almeno un test e un'asserzione per gli artifact `verification_artifact`;
- richiedere contenuto sorgente non commento per gli altri artifact sorgente;
- eseguire soltanto verificatori Node governati e senza shell;
- non modificare il repository se la verifica fallisce;
- aggiornare file e registro come una singola transazione con rollback;
- non eseguire operazioni Git.

## Controlli minimi

- artifact ID valido e univoco;
- stato iniziale `scaffolded`;
- path registrato e file presente;
- requisito, decisione, macro-requirement e stato coerenti nel sorgente;
- placeholder iniziale assente;
- evidenza minima di comportamento;
- comando di verifica supportato e riuscito;
- stato finale `implemented` e campo `implemented_path`;
- nessun residuo temporaneo dopo successo o fallimento.

## Failure mode

Il comando deve terminare con codice non zero e lasciare file e registro invariati per conferma assente, artifact sconosciuto, stato non promuovibile, file mancante, tracciabilità incoerente, placeholder ancora presente, comportamento assente, verificatore non supportato, verifica fallita o errore transazionale.

# MR-0002ADR-0003REQ-0002GOV-0001 — Promozione verificata, atomica e non distruttiva

## Intent

Impedire che un file incompleto, non verificato o non coerente con il relativo record venga dichiarato come implementato.

## Governance obligation

- The governed implementation must enforce this condition: richiedere la conferma esatta `promote`.
- The governed implementation must enforce this condition: operare su un solo artifact ID esistente e nello stato `scaffolded`.
- The governed implementation must enforce this condition: richiedere `scaffolded_path`, file esistente e tracciabilità coerente con i requisiti collegati.
- The governed implementation must enforce this condition: richiedere `@derivedFromDecision`, `@macroRequirement` e una sola dichiarazione `@implementationStatus scaffolded`.
- The governed implementation must enforce this condition: rifiutare lo specifico placeholder `TODO: implement the governed ... behavior.` generato dallo scaffolder.
- The governed implementation must enforce this condition: richiedere almeno un test e un'asserzione per gli artifact `verification_artifact`.
- The governed implementation must enforce this condition: richiedere contenuto sorgente non commento per gli altri artifact sorgente.
- The governed implementation must enforce this condition: eseguire soltanto verificatori Node governati e senza shell.
- The governed implementation must enforce this condition: non modificare il repository se la verifica fallisce.
- The governed implementation must enforce this condition: aggiornare file e registro come una singola transazione con rollback.
- The governed implementation must enforce this condition: non eseguire operazioni Git.

## Verification obligations

- The verification must confirm this condition: artifact ID valido e univoco.
- The verification must confirm this condition: stato iniziale `scaffolded`.
- The verification must confirm this condition: path registrato e file presente.
- The verification must confirm this condition: requisito, decisione, macro-requirement e stato coerenti nel sorgente.
- The verification must confirm this condition: placeholder iniziale assente.
- The verification must confirm this condition: evidenza minima di comportamento.
- The verification must confirm this condition: comando di verifica supportato e riuscito.
- The verification must confirm this condition: stato finale `implemented` e campo `implemented_path`.
- The verification must confirm this condition: nessun residuo temporaneo dopo successo o fallimento.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

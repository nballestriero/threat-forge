# MR-0002ADR-0003REQ-0002GOV-0002 — Copertura deterministica della promozione di scaffold

## Intento

Dimostrare automaticamente che la promozione accetta soltanto scaffold completi e verificati e che ogni fallimento è privo di mutazioni persistenti.

## Obbligo di governance

Un controllo locale attivo deve verificare:

- tracciabilità del tool di promozione;
- mapping del task VS Code e conferma esplicita;
- caso positivo con aggiornamento coerente di sorgente e registro;
- esecuzione reale del comando di verifica;
- assenza di file temporanei dopo la transazione;
- fixture negative governate;
- invarianza del workspace per ogni fixture negativa.

## Copertura negativa minima

- conferma mancante;
- artifact ID sconosciuto;
- record già `implemented`;
- file sorgente mancante;
- placeholder dello scaffolder ancora presente;
- dichiarazione `@implementationStatus scaffolded` mancante;
- comportamento di test assente;
- comando di verifica fallito;
- comando di verifica non supportato.

## Acceptance

Il requisito è soddisfatto quando il checker esegue il caso positivo e tutte le fixture negative, rileva il diagnostico atteso, prova l'assenza di mutazioni sui fallimenti e il `repo-check` lo esegue come gate attivo.

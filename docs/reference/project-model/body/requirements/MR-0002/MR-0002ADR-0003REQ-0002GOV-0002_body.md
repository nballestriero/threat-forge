# MR-0002ADR-0003REQ-0002GOV-0002 — Copertura deterministica della promozione di scaffold

## Intent

Dimostrare automaticamente che la promozione accetta soltanto scaffold completi e verificati e che ogni fallimento è privo di mutazioni persistenti.

## Governance obligation

- The governed implementation must enforce this condition: tracciabilità del tool di promozione.
- The governed implementation must enforce this condition: mapping del task VS Code e conferma esplicita.
- The governed implementation must enforce this condition: caso positivo con aggiornamento coerente di sorgente e registro.
- The governed implementation must enforce this condition: esecuzione reale del comando di verifica.
- The governed implementation must enforce this condition: assenza di file temporanei dopo la transazione.
- The governed implementation must enforce this condition: fixture negative governate.
- The governed implementation must enforce this condition: invarianza del workspace per ogni fixture negativa.

## Verification obligations

- The verification must confirm this condition: conferma mancante.
- The verification must confirm this condition: artifact ID sconosciuto.
- The verification must confirm this condition: record già `implemented`.
- The verification must confirm this condition: file sorgente mancante.
- The verification must confirm this condition: placeholder dello scaffolder ancora presente.
- The verification must confirm this condition: dichiarazione `@implementationStatus scaffolded` mancante.
- The verification must confirm this condition: comportamento di test assente.
- The verification must confirm this condition: comando di verifica fallito.
- The verification must confirm this condition: comando di verifica non supportato.
- The verification must confirm this condition: Il requisito è soddisfatto quando il checker esegue il caso positivo e tutte le fixture negative, rileva il diagnostico atteso, prova l'assenza di mutazioni sui fallimenti e il `repo-check` lo esegue come gate attivo.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

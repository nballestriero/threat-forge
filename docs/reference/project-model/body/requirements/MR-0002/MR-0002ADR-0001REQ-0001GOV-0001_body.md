# MR-0002ADR-0001REQ-0001GOV-0001 — Adapter IDE sottile e piano senza scrittura

## Intento

Garantire che la prima integrazione di authoring implementativo sia sicura, riutilizzabile e indipendente dall'interfaccia VS Code.

## Obbligo di governance

La capacità deve:

- mantenere validazione e costruzione del piano in un tool governato indipendente dall'IDE;
- usare VS Code soltanto per raccogliere input, avviare il tool e mostrare l'output;
- rifiutare requisiti inesistenti e path non validi;
- non creare, modificare o eliminare file;
- non aggiornare registri o tracciabilità;
- non eseguire commit o push;
- terminare con codice di uscita non zero quando gli input non rispettano il modello governato.

## Controlli minimi

- requisito presente in uno dei registri `MR-*.requirements.registry.yml`;
- tipo di artefatto appartenente a un insieme esplicito supportato;
- path relativo alla root e privo di attraversamenti verso directory superiori;
- output contenente requisito, tipo, path, tracciabilità prevista e verifica proposta;
- working tree invariato dopo l'esecuzione.

## Failure mode

Il controllo deve fallire per requisito sconosciuto, tipo non supportato, path assoluto, path esterno alla root o input obbligatorio mancante.

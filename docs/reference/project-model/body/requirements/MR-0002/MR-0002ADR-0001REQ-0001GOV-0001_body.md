# MR-0002ADR-0001REQ-0001GOV-0001 — Adapter IDE sottile e piano senza scrittura

## Intent

Garantire che la prima integrazione di authoring implementativo sia sicura, riutilizzabile e indipendente dall'interfaccia VS Code.

## Governance obligation

- The governed implementation must enforce this condition: mantenere validazione e costruzione del piano in un tool governato indipendente dall'IDE.
- The governed implementation must enforce this condition: usare VS Code soltanto per raccogliere input, avviare il tool e mostrare l'output.
- The governed implementation must enforce this condition: rifiutare requisiti inesistenti e path non validi.
- The governed implementation must enforce this condition: non creare, modificare o eliminare file.
- The governed implementation must enforce this condition: non aggiornare registri o tracciabilità.
- The governed implementation must enforce this condition: non eseguire commit o push.
- The governed implementation must enforce this condition: terminare con codice di uscita non zero quando gli input non rispettano il modello governato.

## Verification obligations

- The verification must confirm this condition: requisito presente in uno dei registri `MR-*.requirements.registry.yml`.
- The verification must confirm this condition: tipo di artefatto appartenente a un insieme esplicito supportato.
- The verification must confirm this condition: path relativo alla root e privo di attraversamenti verso directory superiori.
- The verification must confirm this condition: output contenente requisito, tipo, path, tracciabilità prevista e verifica proposta.
- The verification must confirm this condition: working tree invariato dopo l'esecuzione.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

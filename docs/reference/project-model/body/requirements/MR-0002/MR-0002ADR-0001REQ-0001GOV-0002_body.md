# MR-0002ADR-0001REQ-0001GOV-0002 — Copertura deterministica della pianificazione implementativa

## Intent

Dimostrare che il pianificatore implementativo applica realmente i vincoli read-only e rifiuta input incompatibili con il modello governato.

## Governance obligation

- The governed implementation must enforce this condition: Il pianificatore e il relativo adapter VS Code devono essere verificati da un controllo deterministico registrato nel catalogo locale dei check.
- The governed implementation must enforce this condition: presenza della tracciabilità del tool verso requisito, decisione e macro-requirement.
- The governed implementation must enforce this condition: presenza del task VS Code e degli argomenti obbligatori.
- The governed implementation must enforce this condition: successo di un caso valido con output completo.
- The governed implementation must enforce this condition: rifiuto deterministico dei principali input invalidi.
- The governed implementation must enforce this condition: assenza di mutazioni del working tree durante la pianificazione e la verifica.

## Verification obligations

- The verification must confirm this condition: Le fixture negative devono coprire requisito inesistente, tipo non supportato, path assoluto, attraversamento della directory padre, input obbligatorio mancante e assenza della modalità `--dry-run` esplicita.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

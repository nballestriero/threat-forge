# MR-0002ADR-0003REQ-0001 — Creazione guidata di uno scaffold implementativo governato

## Intent

Create the first source scaffold from a governed Requirement while keeping source declarations and implementation trace data coherent from the initial write.

## Functional obligation

- ThreatForge must accept a validated Requirement, artifact type, title and target path from the governed implementation planner.
- The scaffolder must create a new source scaffold at the validated target path.
- The scaffolder must add `@implementsRequirement`, `@derivedFromDecision`, `@macroRequirement` and `@implementationStatus scaffolded` declarations.
- The scaffolder must assign a deterministic governed implementation artifact identifier.
- The scaffolder must append one matching `scaffolded` record to the implementation trace registry.
- The scaffolder must require explicit confirmation before writing.
- The scaffolder must refuse to overwrite an existing file or artifact record.
- The scaffolder must report the identifier, path, state and verification command.
- The scaffolder must be invokable through a VS Code task.

## Scope

- Includes: `tool`, `source-module` and `test` artifact types
- Includes: supported JavaScript and TypeScript source files
- Includes: canonical repository-root execution
- Includes: atomic source and implementation trace creation
- Excludes: autonomous application-logic generation
- Excludes: existing-file overwrite and existing-scaffold modification
- Excludes: automatic promotion, commit, push or editor opening

## Acceptance

- The requirement is accepted when a confirmed VS Code or CLI operation creates one new scaffold and one matching trace record.
- The requirement is accepted when source and registry records contain the same governed identifiers and relations.
- The requirement is accepted when an existing path or artifact identifier causes the operation to fail without mutation.
- The requirement is accepted when an unconfirmed operation leaves the repository unchanged.
- The requirement is accepted when the repository gate passes immediately after successful scaffold creation.

# MR-0002ADR-0003REQ-0001 — Creazione guidata di uno scaffold implementativo governato

## Intento

Permettere di iniziare la scrittura del codice da un requisito governato mantenendo file e tracciabilità coerenti fin dalla creazione.

## Obbligo funzionale

ThreatForge deve ricevere requisito, tipo di artefatto, titolo e path già validabili dal pianificatore e deve:

- creare uno scaffold sorgente nel path richiesto;
- inserire le dichiarazioni `@implementsRequirement`, `@derivedFromDecision`, `@macroRequirement` e `@implementationStatus scaffolded`;
- assegnare un identificativo implementativo deterministico;
- aggiungere un record `scaffolded` all'implementation trace registry;
- stampare path, identificativo, stato e comando di verifica;
- rendere la capacità richiamabile da un task VS Code.

## Ambito

Incluso:

- tipi `tool`, `source-module` e `test`;
- file JavaScript e TypeScript già ammessi dal pianificatore;
- creazione dalla root canonica;
- aggiornamento dell'implementation trace registry;
- conferma esplicita prima della scrittura.

Escluso:

- generazione autonoma della logica applicativa;
- sovrascrittura di file;
- modifica di scaffold esistenti;
- promozione automatica a `implemented`;
- commit o push automatici;
- apertura automatica nell'editor.

## Acceptance

Il requisito è soddisfatto quando il task VS Code crea un nuovo scaffold tracciato, il file e il record usano gli stessi metadati e il `repo-check` passa immediatamente dopo la creazione.

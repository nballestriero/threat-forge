# MR-0002ADR-0006REQ-0002 — Live VS Code assistance for governed Markdown bodies

## Intent

Expose contextual governed Markdown completions and diagnostics directly inside Visual Studio Code.

## Functional obligation

- The VS Code adapter must invoke the shared Markdown assistance core for governed body documents.
- The VS Code adapter must provide section heading completions at applicable Markdown positions.
- The VS Code adapter must provide controlled value completions inside applicable controlled sections.
- The VS Code adapter must publish live diagnostics returned by the shared core.
- The VS Code adapter must expose canonical hover information returned by the shared core.
- The VS Code adapter must expose applicable quick fixes returned by the shared core.
- The VS Code adapter must analyze the current unsaved document text.
- The VS Code adapter must preserve existing governed task workflows for command execution.

## Scope

- Includes: governed Markdown body completion
- Includes: live diagnostics
- Includes: hover information
- Includes: quick fixes
- Includes: current unsaved editor state
- Excludes: canonical rule ownership inside the extension
- Excludes: automatic repository mutation

## Acceptance

- The requirement is accepted when typing `##` in an ADR proposes `Status` as the first missing required section.
- The requirement is accepted when completing `Status` makes `Context` the highest-priority section suggestion.
- The requirement is accepted when the `Status` section proposes only canonical decision status labels.
- The requirement is accepted when a missing required section appears in the VS Code Problems view.
- The requirement is accepted when a quick fix uses the canonical replacement supplied by the shared core.

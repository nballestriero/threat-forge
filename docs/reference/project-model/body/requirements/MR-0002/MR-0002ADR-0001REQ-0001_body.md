# MR-0002ADR-0001REQ-0001 — Pianificazione guidata di un artefatto implementativo da requisito governato

## Intento

Ridurre gli errori iniziali di implementazione producendo un piano deterministico prima della creazione di codice o altri artefatti tecnici.

## Obbligo funzionale

ThreatForge deve permettere di:

- selezionare un requisito esistente dai registri governati;
- acquisire tipo, titolo e path proposto dell'artefatto;
- derivare dal requisito il macro-requirement e la decisione di origine;
- validare identificativo, tipo e path prima di qualsiasi scrittura;
- mostrare un piano contenente requisito collegato, path, dichiarazioni di tracciabilità previste e comando di verifica.

Il primo incremento deve operare esclusivamente in modalità senza scrittura.

## Ambito

Incluso:

- requisiti funzionali e requisiti di governance esistenti;
- pianificazione di tool, componenti applicativi, test e fixture;
- output leggibile nel terminale o nell'interfaccia IDE;
- invocazione dalla root canonica del repository.

Escluso:

- creazione effettiva del file;
- modifica dell'implementation trace registry;
- esecuzione automatica di commit o push;
- generazione autonoma del contenuto applicativo.

## Acceptance

Il requisito è soddisfatto quando un comando governato, richiamabile da VS Code, riceve un requisito valido e i dati minimi dell'artefatto, produce un piano deterministico e lascia invariato il repository.

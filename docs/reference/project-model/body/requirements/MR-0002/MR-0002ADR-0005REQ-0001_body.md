# MR-0002ADR-0005REQ-0001 — Catalogo locale di task VS Code ThreatForge

## Intento

Rendere accessibili da VS Code i principali comandi locali governati senza duplicare la loro logica e senza introdurre una custom extension.

## Obbligo funzionale

Il workspace tecnico locale deve fornire un catalogo VS Code con task per:

- eseguire il `repo-check` locale;
- eseguire singolarmente i tre check attivi;
- simulare la creazione di un requisito funzionale;
- simulare la creazione di un requisito di governance;
- simulare la creazione dell'handoff archive.

## Ambito

Incluso:

- file `.vscode/tasks.json` nella root canonica;
- input interattivi per identificativi e titoli dei requisiti;
- esecuzione dei comandi dalla root del repository;
- label utente con prefisso `ThreatForge:`.

Escluso:

- estensione VS Code dedicata;
- scrittura non simulata di documenti;
- produzione non simulata dell'handoff;
- duplicazione della logica dei tool CLI.

## Acceptance

Il requisito è soddisfatto quando VS Code espone i sette task definiti dalla decisione e ciascun task invoca il corrispondente comando governato dalla root del repository.

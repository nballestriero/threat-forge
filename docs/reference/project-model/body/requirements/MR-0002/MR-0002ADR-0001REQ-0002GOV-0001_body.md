# MR-0002ADR-0001REQ-0002GOV-0001 — View-model canonico e tooltip accessibili

## Intent

Impedire che backend e frontend ricostruiscano autonomamente il significato dei campi controllati e garantire che le descrizioni siano accessibili.

## Governance obligation

- The governed implementation must enforce this condition: Il backend deve risolvere i metadati dei campi controllati attraverso il catalogo canonico e deve esporre un view-model stabile e indipendente dalla struttura fisica dei registri.
- The governed implementation must enforce this condition: valori ammessi.
- The governed implementation must enforce this condition: label di dominio.
- The governed implementation must enforce this condition: descrizioni.
- The governed implementation must enforce this condition: alias.
- The governed implementation must enforce this condition: colori con significato governato.
- The governed implementation must enforce this condition: regole di applicabilita.
- The governed implementation must enforce this condition: Ogni componente che rappresenta un campo controllato deve rendere disponibile la descrizione canonica tramite hover, focus da tastiera, tecnologia assistiva e alternativa testuale quando il tooltip non e disponibile.
- The governed implementation must enforce this condition: Il colore puo supportare la lettura ma non deve essere l'unico mezzo per comunicare stato o significato.

## Verification obligations

- The verification must confirm this condition: provenienza dei metadati restituiti dall'API.
- The verification must confirm this condition: corrispondenza tra valore corrente e value set applicabile.
- The verification must confirm this condition: assenza di enum e descrizioni di dominio nel frontend.
- The verification must confirm this condition: tooltip o descrizione associata al valore.
- The verification must confirm this condition: apertura tramite hover e focus.
- The verification must confirm this condition: presenza di label testuale.
- The verification must confirm this condition: assenza di informazione comunicata soltanto dal colore.
- The verification must confirm this condition: comportamento definito sui dispositivi senza hover.
- The verification must confirm this condition: coerenza tra tooltip e view-model API.
- The verification must confirm this condition: separazione tra record strutturato e rendering del body Markdown.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

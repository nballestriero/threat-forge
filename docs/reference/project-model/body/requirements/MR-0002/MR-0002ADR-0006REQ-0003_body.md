# MR-0002ADR-0006REQ-0003 — Web editor reuse of governed Markdown assistance

## Intent

Provide the Governance Console editor with the same governed Markdown semantics used by Visual Studio Code.

## Functional obligation

- The web editor adapter must invoke the shared Markdown assistance core contract.
- The web editor adapter must provide canonical section completions.
- The web editor adapter must provide applicable controlled value completions.
- The web editor adapter must display diagnostics returned by the shared core.
- The web editor adapter must display canonical hover information.
- The web editor adapter must expose applicable quick fixes.
- The web editor adapter must preserve the current unsaved editor state during analysis.

## Scope

- Includes: future Governance Console Markdown editor
- Includes: Monaco or CodeMirror integration
- Includes: completion, diagnostics, hover and quick fixes
- Excludes: browser ownership of canonical document rules
- Excludes: direct persistence without a governed authoring command

## Acceptance

- The requirement is accepted when the web editor consumes the same analysis contract as VS Code.
- The requirement is accepted when identical document state produces equivalent semantic completions in both adapters.
- The requirement is accepted when identical document state produces equivalent diagnostic rule identifiers in both adapters.
- The requirement is accepted when web analysis remains independent of the concrete editor library.

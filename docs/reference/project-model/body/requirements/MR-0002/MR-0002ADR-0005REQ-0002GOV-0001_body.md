# MR-0002ADR-0005REQ-0002GOV-0001 — Adapter VS Code sottile e privo di regole canoniche duplicate

## Intent

Garantire che l'integrazione VS Code rimanga un adapter locale del core governato e non diventi una seconda fonte delle regole di authoring.

## Governance obligation

- The governed implementation must enforce this condition: invocare esclusivamente entry point CLI governati.
- The governed implementation must enforce this condition: usare label visibili con prefisso `ThreatForge:`.
- The governed implementation must enforce this condition: eseguire i comandi dalla root del repository.
- The governed implementation must enforce this condition: mantenere separati preview e creazione confermata.
- The governed implementation must enforce this condition: lasciare al core la selezione dinamica dei valori canonici.
- The governed implementation must enforce this condition: lasciare al core preview, conferma, scrittura atomica e controlli successivi.
- The governed implementation must enforce this condition: associare ai documenti YAML `*.governed-document-authoring.yml` soltanto uno schema generato dal core.
- The governed implementation must enforce this condition: non associare lo schema di richiesta authoring ai registri YAML canonici.
- The governed implementation must enforce this condition: utilizzare snippet generati o verificati rispetto al contratto canonico.
- The governed implementation must enforce this condition: non contenere liste statiche di MR, ADR, requisiti padre, status o tipi di requisito.
- The governed implementation must enforce this condition: non introdurre una custom extension.
- The governed implementation must enforce this condition: Il valore predefinito di ogni conferma deve essere non distruttivo.
- The governed implementation must enforce this condition: Non deve esistere un task che bypassi la preview o trasformi una semplice selezione dalla palette in una scrittura incondizionata.
- The governed implementation must enforce this condition: I registri YAML canonici e i body governati devono essere modificati esclusivamente dal core dopo preview e conferma esplicita.

## Verification obligations

- The verification must confirm this condition: ogni task richiami un comando governato esistente.
- The verification must confirm this condition: il `cwd` sia `${workspaceFolder}`.
- The verification must confirm this condition: le label rispettino il prefisso canonico.
- The verification must confirm this condition: il task di preview non abiliti la scrittura.
- The verification must confirm this condition: il task di creazione non contenga opzioni di conferma automatica.
- The verification must confirm this condition: i file `.vscode` non contengano enum canonici duplicati.
- The verification must confirm this condition: lo schema associato sia quello prodotto dal core.
- The verification must confirm this condition: l'associazione dello schema riguardi `*.governed-document-authoring.yml` e non i registri YAML canonici.
- The verification must confirm this condition: gli snippet siano coerenti con i template governati.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

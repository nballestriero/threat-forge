# MR-0002ADR-0002REQ-0001GOV-0001 — Gate obbligatorio prima delle mutazioni Git

## Intent

Impedire che stage, commit o push avvengano quando la root canonica non supera i controlli governati.

## Governance obligation

- The governed implementation must enforce this condition: eseguire `node tools/repo-check.mjs` prima di qualsiasi mutazione Git.
- The governed implementation must enforce this condition: richiedere un messaggio non vuoto in modalità `--commit-push`.
- The governed implementation must enforce this condition: richiedere un branch non detached e un upstream configurato.
- The governed implementation must enforce this condition: eseguire stage soltanto dopo il successo dei gate.
- The governed implementation must enforce this condition: verificare che esista almeno un file staged.
- The governed implementation must enforce this condition: eseguire `git diff --cached --check` prima del commit.
- The governed implementation must enforce this condition: eseguire push soltanto dopo un commit riuscito.
- The governed implementation must enforce this condition: non usare shell interpolation per costruire i comandi Git.

## Verification obligations

- The verification must confirm this condition: modalità supportata.
- The verification must confirm this condition: contesto Git valido.
- The verification must confirm this condition: gate canonico riuscito.
- The verification must confirm this condition: lista staged non vuota.
- The verification must confirm this condition: diff staged senza errori.
- The verification must confirm this condition: commit riuscito.
- The verification must confirm this condition: push riuscito.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

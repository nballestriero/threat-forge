# MR-0002ADR-0002REQ-0001GOV-0001 — Gate obbligatorio prima delle mutazioni Git

## Intento

Impedire che stage, commit o push avvengano quando la root canonica non supera i controlli governati.

## Obbligo di governance

Il runner deve:

- eseguire `node tools/repo-check.mjs` prima di qualsiasi mutazione Git;
- richiedere un messaggio non vuoto in modalità `--commit-push`;
- richiedere un branch non detached e un upstream configurato;
- eseguire stage soltanto dopo il successo dei gate;
- verificare che esista almeno un file staged;
- eseguire `git diff --cached --check` prima del commit;
- eseguire push soltanto dopo un commit riuscito;
- non usare shell interpolation per costruire i comandi Git.

## Controlli minimi

- modalità supportata;
- contesto Git valido;
- gate canonico riuscito;
- lista staged non vuota;
- diff staged senza errori;
- commit riuscito;
- push riuscito.

## Failure mode

Il runner deve terminare con codice non zero e non proseguire quando manca il messaggio, il repository non è valido, il branch è detached, manca l'upstream, fallisce un gate, non esistono cambi staged, il diff è invalido, il commit fallisce o il push fallisce.

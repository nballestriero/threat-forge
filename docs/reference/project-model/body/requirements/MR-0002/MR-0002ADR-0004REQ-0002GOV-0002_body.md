# MR-0002ADR-0004REQ-0002GOV-0002 — Copertura negativa del controllo degli header governati

## Intent

Demonstrate that complete-model header validation rejects real registry-to-body inconsistencies rather than only confirming the current valid corpus.

## Governance obligation

- Every complete-model checker must execute versioned negative fixtures for its governed registry and body representation.
- Each negative fixture must declare at least one expected stable rule identifier.
- A negative fixture must not pass without producing every diagnostic declared by that fixture.

## Verification obligations

- The verification must cover missing titles, legacy title fields, missing bodies, missing or duplicate H1 headings, legacy separators and title divergence where applicable to the model.
- The verification must compare observed stable rule identifiers with the fixture registry.
- The verification must report a deterministic count of executed negative fixtures without warning or error on the valid workspace.

## Failure conditions

- The verification must fail when a negative fixture passes unexpectedly or omits an expected stable diagnostic.
- The verification must fail when a fixture registry or fixture payload is missing, unreadable or empty.

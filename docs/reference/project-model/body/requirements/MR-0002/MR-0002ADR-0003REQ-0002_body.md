# MR-0002ADR-0003REQ-0002 — Promozione governata di uno scaffold implementativo

## Intent

Promote a scaffold to implemented state only after real behavior exists and its governed verification succeeds.

## Functional obligation

- ThreatForge must select a promotion target by implementation artifact identifier.
- The promotion tool must accept only implementation trace records in `scaffolded` state.
- The promotion tool must resolve the source path, linked Requirement and verification command from the implementation trace registry.
- The promotion tool must validate source trace declarations against the registry record.
- The promotion tool must reject the generated placeholder and source files without implemented behavior.
- The promotion tool must execute the governed verification command without invoking a shell.
- The promotion tool must atomically replace source and registry state from `scaffolded` to `implemented`.
- The promotion tool must preserve artifact paths and linked Requirements during promotion.
- The promotion tool must require explicit confirmation and remain invokable through VS Code.

## Scope

- Includes: artifacts created by the governed scaffolder
- Includes: selection by implementation artifact identifier
- Includes: governed `node --test`, `node --check` and repository-gate verification
- Includes: atomic source and implementation trace updates
- Excludes: autonomous behavior or test authoring
- Excludes: promotion of planned, implemented, deprecated or superseded records
- Excludes: path, Requirement, commit or push changes

## Acceptance

- The requirement is accepted when only a scaffold with real behavior and successful verification is promoted.
- The requirement is accepted when source and trace registry both declare `implemented` after promotion.
- The requirement is accepted when a failed verification leaves both artifacts unchanged.
- The requirement is accepted when placeholder or inconsistent source content is rejected.
- The requirement is accepted when the repository gate passes immediately after successful promotion.

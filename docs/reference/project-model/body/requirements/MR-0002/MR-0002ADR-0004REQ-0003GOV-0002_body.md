# MR-0002ADR-0004REQ-0003GOV-0002 — Validazione deterministica del catalogo, dello schema e del wizard

## Intent

Garantire che catalogo, JSON Schema e wizard CLI rappresentino in modo coerente e verificabile lo stesso contratto di authoring.

## Governance obligation

- The governed implementation must enforce this condition: Il catalogo, lo schema e il wizard devono essere validati deterministicamente rispetto alle fonti canoniche e tra loro.
- The governed implementation must enforce this condition: l'ordinamento degli elementi deve essere stabile.
- The governed implementation must enforce this condition: il contenuto generato deve essere riproducibile.
- The governed implementation must enforce this condition: gli enum dello schema devono coincidere con i valori del catalogo.
- The governed implementation must enforce this condition: le descrizioni dello schema devono coincidere con i significati canonici.
- The governed implementation must enforce this condition: le condizioni sul requisito padre devono coincidere con le regole del tipo concreto.
- The governed implementation must enforce this condition: preview e creazione devono produrre lo stesso piano documentale.
- The governed implementation must enforce this condition: la creazione deve applicare interamente il piano oppure non applicarlo.

## Verification obligations

- The verification must confirm this condition: tipo concreto valido.
- The verification must confirm this condition: valore `specialized` usato impropriamente come tipo.
- The verification must confirm this condition: tipo non registrato.
- The verification must confirm this condition: macro-requirement inesistente.
- The verification must confirm this condition: ADR inesistente o appartenente a un'altra macro-requirement.
- The verification must confirm this condition: requisito padre inesistente o appartenente a un'altra macro-requirement.
- The verification must confirm this condition: requisito padre vietato dal tipo selezionato.
- The verification must confirm this condition: requisito padre obbligatorio ma assente.
- The verification must confirm this condition: divergenza tra catalogo e JSON Schema.
- The verification must confirm this condition: tentativo di scrittura senza conferma.
- The verification must confirm this condition: errore durante la creazione del secondo artefatto.
- The verification must confirm this condition: riesecuzione di una creazione gia applicata.
- The verification must confirm this condition: assenza di mutazioni dopo ogni rifiuto o errore.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.
- The verification must fail when an invalid case passes without the expected stable diagnostic.

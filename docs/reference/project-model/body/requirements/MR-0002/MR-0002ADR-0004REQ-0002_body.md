# MR-0002ADR-0004REQ-0002 — Controllo degli header dei body governati

## Intent

Keep every governed Markdown H1 coherent with the canonical identifier and title stored in its registry record.

## Functional obligation

- ThreatForge must validate title-to-H1 coherence for every governed record that declares a `body_path`.
- Each applicable validator must report missing bodies, missing H1 headings, duplicate H1 headings, missing registry titles and non-canonical heading mirrors.
- Complete-model checkers must own header validation for document models whose corpus migration is complete.
- A transitional header checker must retain only document models that do not yet have an active complete-model checker.
- The transitional checker must be removed after the final Requirement complete-model checker becomes active.
- Active validators must require the canonical `# <id> — <title>` heading form.

## Scope

- Includes: Macro-requirement, Decision, Functional Requirement and Governance Requirement bodies
- Includes: complete-model ownership of migrated document types
- Includes: temporary residual coverage for unmigrated Governance Requirements
- Excludes: overlapping validation of models already owned by complete-model checkers
- Excludes: permanent legacy compatibility behavior

## Acceptance

- The requirement is accepted when a missing body or H1 produces a deterministic error.
- The requirement is accepted when multiple H1 headings produce a deterministic error.
- The requirement is accepted when registry `title` is missing or differs from the body title.
- The requirement is accepted when a legacy hyphen separator is rejected.
- The requirement is accepted when each migrated model has one exclusive complete-model owner.
- The requirement is accepted when transitional coverage contains only models awaiting complete-model activation.

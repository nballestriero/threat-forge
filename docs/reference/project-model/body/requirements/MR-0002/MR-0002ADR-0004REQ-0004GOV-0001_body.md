# MR-0002ADR-0004REQ-0004GOV-0001 — Preview obbligatoria, conferma esplicita e scrittura atomica

## Intent

Impedire mutazioni parziali o non intenzionali durante l'authoring guidato della documentazione governata.

## Governance obligation

- The governed implementation must enforce this condition: validazione della richiesta.
- The governed implementation must enforce this condition: pianificazione e preview senza side effect.
- The governed implementation must enforce this condition: applicazione confermata.
- The governed implementation must enforce this condition: controlli successivi alla scrittura.
- The governed implementation must enforce this condition: Qualsiasi modalita che possa modificare registri o body deve richiedere un token di conferma esplicito e documentato.
- The governed implementation must enforce this condition: Le operazioni su piu artefatti devono essere trattate come una singola transazione logica con rollback in caso di errore.

## Verification obligations

- The verification must confirm this condition: preview priva di mutazioni.
- The verification must confirm this condition: scrittura respinta senza conferma.
- The verification must confirm this condition: conferma errata respinta.
- The verification must confirm this condition: file esistente non sovrascritto quando il contratto prevede create-only.
- The verification must confirm this condition: rollback del registro quando fallisce la creazione del body.
- The verification must confirm this condition: rollback del body quando fallisce l'aggiornamento del registro.
- The verification must confirm this condition: esecuzione dei gate applicabili dopo una scrittura riuscita.
- The verification must confirm this condition: report deterministico dell'operazione.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

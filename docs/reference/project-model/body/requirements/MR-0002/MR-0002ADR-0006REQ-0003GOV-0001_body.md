# MR-0002ADR-0006REQ-0003GOV-0001 — Semantic equivalence across editor adapters

## Intent

Keep editor integrations interchangeable at the governed semantic boundary.

## Governance obligation

- Every editor adapter must consume the same versioned Markdown assistance contract.
- Every editor adapter must preserve canonical diagnostic rule identifiers.
- Every editor adapter must preserve canonical completion identities and ordering semantics.
- Editor-specific range conversions must not change diagnostic meaning.
- An editor adapter must not become a canonical source of document profiles or controlled values.

## Verification obligations

- The verification must execute shared contract fixtures through every supported editor adapter.
- The verification must compare semantic completion identities across adapters.
- The verification must compare diagnostic rule identifiers across adapters.
- The verification must compare applicable quick-fix identities across adapters.
- The verification must allow only editor-specific coordinate and presentation differences.

## Failure conditions

- The verification must fail when two adapters return different semantic completion identities for identical input.
- The verification must fail when two adapters return different diagnostic rule identifiers for identical input.
- The verification must fail when an adapter omits a canonical quick fix without a governed capability exception.
- The verification must fail when an adapter embeds an independent document profile.

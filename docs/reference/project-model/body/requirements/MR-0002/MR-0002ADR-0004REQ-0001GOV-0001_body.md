# MR-0002ADR-0004REQ-0001GOV-0001 — Coerenza deterministica tra record di registro e body generati

## Intent

Il generatore non deve introdurre incoerenza tra registry e body Markdown.

## Governance obligation

- The governed implementation must enforce this condition: Ogni documento governato generato deve usare il registro come fonte canonica per `id`, `title`, `status`, `requirement_type`, relazioni e `body_path`.
- The governed implementation must enforce this condition: Il body generato deve includere un H1 derivato dall'identificativo e dal titolo generati per il record del registro.

## Verification obligations

- The verification must confirm this condition: impedire la sovrascrittura di body esistenti.
- The verification must confirm this condition: impedire la duplicazione di id gia presenti nel registro.
- The verification must confirm this condition: derivare il prossimo id dal contesto MR/ADR o dal requisito padre.
- The verification must confirm this condition: creare un path coerente con l'id generato.
- The verification must confirm this condition: supportare una modalita dry-run senza side effect.
- The verification must confirm this condition: produrre un body con H1 leggibile e coerente.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.
- The verification must fail when an invalid case passes without the expected stable diagnostic.

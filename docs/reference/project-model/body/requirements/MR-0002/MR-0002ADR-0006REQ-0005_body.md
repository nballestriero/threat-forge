# MR-0002ADR-0006REQ-0005 — Unified VS Code assistance extension for engine and Target Project workspaces

## Intent

Provide one installable VS Code extension that exposes governed Markdown assistance consistently in the ThreatForge engine repository and in independently opened Target Project workspaces.

## Functional obligation

- The VS Code integration must use one installable extension package and one extension identifier for engine and Target Project workspaces.
- The extension must classify each workspace folder deterministically as a ThreatForge engine, a Target Project or an unsupported workspace.
- The extension must use the opened repository root as the analysis root when the workspace is the ThreatForge engine.
- The extension must resolve an explicit workspace-scoped threatforge.engineRoot and the opened folder as targetRoot when the workspace is a Target Project.
- The extension must remain silent when the opened workspace is neither a ThreatForge engine nor a declared Target Project.
- The extension must register only one effective set of completion, diagnostic, hover and quick-fix providers for each governed Markdown document.
- The extension must reuse the shared governed Markdown assistance core in engine mode.
- The extension must reuse the Target Project assistance composition root in target mode.
- The extension must preserve canonical section, controlled-value and governed-reference completions in both supported modes.
- The extension must not classify a workspace as a Target Project solely from a user-level or globally inherited engine-root setting.
- The Target Project workspace materializer must recommend the unified extension identifier.
- The unified installation workflow must replace the previously installed engine and Target Project extension packages without requiring manual per-workspace enablement.

## Scope

- Includes: one unified VSIX package
- Includes: deterministic workspace-folder classification
- Includes: ThreatForge engine Markdown assistance
- Includes: external Target Project Markdown assistance
- Includes: repository-contained Target Project Markdown assistance
- Includes: governed section and controlled-value completions
- Includes: governed BAE reference completions
- Includes: diagnostics, hover information and quick fixes
- Includes: clean migration from the two previous extension packages
- Excludes: duplication of canonical documentation rules inside the extension
- Excludes: modification of governed documents during analysis
- Excludes: web editor integration changes
- Excludes: automatic repository commit or push

## Acceptance

- The requirement is accepted when installing only the unified extension provides governed Markdown assistance in the ThreatForge repository.
- The requirement is accepted when opening an external Target Project with a valid workspace-scoped engine root provides the same canonical assistance.
- The requirement is accepted when opening the repository-contained case study provides the same canonical assistance through its relative engine root.
- The requirement is accepted when a generic Markdown workspace produces no ThreatForge error or completion provider.
- The requirement is accepted when the ThreatForge workspace does not produce a missing target engine-root diagnostic.
- The requirement is accepted when typing a canonical section prefix produces the expected profile-derived completion in all supported workspace modes.
- The requirement is accepted when typing a governed BAE reference prefix in an eligible Target Project position produces only target-local BAE completions.
- The requirement is accepted when the installed extension list contains one active ThreatForge Markdown assistance extension rather than two competing packages.

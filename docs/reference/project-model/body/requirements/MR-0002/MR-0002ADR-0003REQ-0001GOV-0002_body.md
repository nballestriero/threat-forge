# MR-0002ADR-0003REQ-0001GOV-0002 — Copertura deterministica della creazione di scaffold

## Intent

Dimostrare che lo scaffolder rispetta creazione, tracciabilità, non sovrascrittura e rollback senza affidarsi a verifiche manuali.

## Governance obligation

- The governed implementation must enforce this condition: presenza delle dichiarazioni di tracciabilità nel tool.
- The governed implementation must enforce this condition: mapping corretto del task VS Code.
- The governed implementation must enforce this condition: presenza della conferma esplicita.
- The governed implementation must enforce this condition: creazione positiva in un workspace isolato.
- The governed implementation must enforce this condition: registrazione dello stato `scaffolded`.
- The governed implementation must enforce this condition: validità del risultato tramite il checker di implementation trace.
- The governed implementation must enforce this condition: rifiuto deterministico dei casi negativi governati.
- The governed implementation must enforce this condition: assenza di modifiche al repository reale durante il controllo.

## Verification obligations

- The verification must confirm this condition: conferma mancante.
- The verification must confirm this condition: requisito sconosciuto.
- The verification must confirm this condition: tipo non materializzabile.
- The verification must confirm this condition: path non sicuro.
- The verification must confirm this condition: file già esistente.
- The verification must confirm this condition: path già registrato.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

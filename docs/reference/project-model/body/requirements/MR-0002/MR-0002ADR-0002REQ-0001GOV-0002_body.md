# MR-0002ADR-0002REQ-0001GOV-0002 — Controllo deterministico del runner di repository

## Intent

Rendere rilevabile ogni regressione che trasformi il runner in un percorso capace di saltare i gate o perdere la propria tracciabilità.

## Governance obligation

- The governed implementation must enforce this condition: esista nel path canonico.
- The governed implementation must enforce this condition: dichiari requisito, decisione e macro-requirement implementati.
- The governed implementation must enforce this condition: esponga le modalità `--check` e `--commit-push`.
- The governed implementation must enforce this condition: richiami il `repo-check` canonico.
- The governed implementation must enforce this condition: mantenga l'ordine gate, stage, controllo staged, commit e push.
- The governed implementation must enforce this condition: mantenga il controllo del messaggio e dell'upstream.
- The governed implementation must enforce this condition: sia coperto da fixture negative che rimuovono singole garanzie obbligatorie.

## Verification obligations

- The verification must confirm this condition: verifica statica della sorgente del runner.
- The verification must confirm this condition: esecuzione di tutte le fixture negative registrate.
- The verification must confirm this condition: fallimento della fixture quando la regressione attesa non viene rilevata.
- The verification must confirm this condition: integrazione del checker nel `repo-check` locale.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.
- The verification must fail when an invalid case passes without the expected stable diagnostic.

# MR-0002ADR-0004REQ-0003GOV-0001 — Derivazione esclusiva dei suggerimenti dalle fonti canoniche

## Intent

Impedire che catalogo, schema, wizard CLI o adapter editor mantengano copie divergenti degli identificativi, dei valori controllati o delle relative descrizioni.

## Governance obligation

- The governed implementation must enforce this condition: Tutti i suggerimenti e i vincoli presentati durante l'authoring devono essere derivati dalle fonti canoniche del Project Model.
- The governed implementation must enforce this condition: le macro-requirement devono essere lette dal registro canonico delle macro-requirement.
- The governed implementation must enforce this condition: le ADR devono essere lette dai registri canonici delle decisioni.
- The governed implementation must enforce this condition: i requisiti padre devono essere letti dai registri canonici dei requisiti.
- The governed implementation must enforce this condition: valori, significati e regole di `requirement_type` devono essere letti dal registro canonico dei valori controllati.
- The governed implementation must enforce this condition: identificativi e path devono essere calcolati dal contenuto corrente dei registri.
- The governed implementation must enforce this condition: catalogo e schema devono dichiarare le fonti canoniche dalle quali sono stati derivati.
- The governed implementation must enforce this condition: Codice, task VS Code, setting e snippet non devono contenere liste operative duplicate di MR, ADR, requisiti padre o valori ammessi.
- The governed implementation must enforce this condition: Le fixture negative possono contenere intenzionalmente valori non validi, purche siano isolate dalle fonti operative e identificate come casi di errore.

## Verification obligations

- The verification must confirm this condition: ogni fonte canonica richiesta esista e sia leggibile.
- The verification must confirm this condition: ogni identificativo catalogato provenga da un record canonico.
- The verification must confirm this condition: ogni ADR selezionabile appartenga alla macro-requirement selezionata.
- The verification must confirm this condition: ogni requisito padre selezionabile appartenga alla macro-requirement selezionata.
- The verification must confirm this condition: ogni tipo presentato sia un valore concreto della tassonomia.
- The verification must confirm this condition: significati e regole non siano ridefiniti nel codice o nell'adapter editor.
- The verification must confirm this condition: catalogo e schema conservino la provenienza delle fonti utilizzate.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

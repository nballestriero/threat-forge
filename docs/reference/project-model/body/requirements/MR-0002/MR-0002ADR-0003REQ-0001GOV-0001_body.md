# MR-0002ADR-0003REQ-0001GOV-0001 — Creazione atomica, non distruttiva e stato scaffolded

## Intento

Impedire che la creazione guidata lasci file scollegati, record orfani o implementazioni incomplete marcate come completate.

## Obbligo di governance

La capacità deve:

- richiedere una conferma esplicita di scrittura;
- riusare il contratto di validazione del pianificatore;
- rifiutare un path già presente nel filesystem;
- rifiutare un path già citato nell'implementation trace registry;
- creare il file con semantica create-only;
- registrare lo stato `scaffolded` e il campo `scaffolded_path`;
- inserire `@implementationStatus scaffolded` nei sorgenti creati;
- ripristinare lo stato precedente se file e registro non possono essere aggiornati entrambi;
- non eseguire operazioni Git.

## Controlli minimi

- requisito esistente;
- tipo sorgente supportato;
- path relativo e sicuro;
- titolo su una sola riga;
- conferma esatta `create`;
- identificativo implementativo non duplicato;
- file e record coerenti;
- nessun residuo temporaneo dopo successo o fallimento.

## Failure mode

Il comando deve terminare con codice non zero senza modifiche persistenti per input non valido, conferma assente, path esistente, path già registrato, identificativo duplicato o errore durante la transazione.

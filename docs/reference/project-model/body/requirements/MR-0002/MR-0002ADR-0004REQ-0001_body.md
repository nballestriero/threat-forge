# MR-0002ADR-0004REQ-0001 — Generatore deterministico di documenti governati

## Intento

La creazione manuale di record YAML e body Markdown aumenta il rischio di divergenze tra identificativi, titoli, path e campi controllati.

## Obbligo funzionale

Il modello documentale deve includere almeno un generatore locale capace di creare documenti governati a partire da input minimi forniti dall'autore.

Il generatore deve produrre insieme:

- record del registro governato;
- body Markdown associato;
- identificativo deterministico;
- path del body;
- header del body coerente con il titolo del registro.

## Ambito iniziale

Il primo ambito del generatore copre i requisiti funzionali e i requisiti di governance nei registri governati dei requisiti del Project Model.

## Acceptance

Il requisito e soddisfatto quando esiste un tool locale che puo pianificare in dry-run e generare in write mode un requisito funzionale o di governance senza richiedere all'autore di calcolare manualmente id, body path e H1.

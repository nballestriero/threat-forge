# MR-0002ADR-0005REQ-0003GOV-0001 — Adapter VS Code sottile e generato dalle fonti canoniche

## Intent

Impedire che configurazioni, task, snippet o schemi VS Code diventino una seconda implementazione del Project Model.

## Governance obligation

- The governed implementation must enforce this condition: associazione tra pattern di file e schema.
- The governed implementation must enforce this condition: raccomandazione delle estensioni necessarie.
- The governed implementation must enforce this condition: task che invocano tool governati.
- The governed implementation must enforce this condition: presentazione delle proiezioni generate dal core.
- The governed implementation must enforce this condition: Enum, descrizioni, relazioni, alias, identificativi e regole condizionali devono essere derivati dal catalogo canonico e non mantenuti manualmente nei file `.vscode`.
- The governed implementation must enforce this condition: La materializzazione deve preservare le configurazioni non gestite e deve essere idempotente.

## Verification obligations

- The verification must confirm this condition: associazione dello schema ai soli file di richiesta previsti.
- The verification must confirm this condition: assenza di associazione diretta ai registri canonici.
- The verification must confirm this condition: schema corrente rispetto alle fonti.
- The verification must confirm this condition: task mappati ai tool governati.
- The verification must confirm this condition: assenza di liste operative duplicate in task, settings e snippet.
- The verification must confirm this condition: idempotenza della materializzazione.
- The verification must confirm this condition: nessuna modifica a file non gestiti.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

# MR-0005ADR-0001REQ-0003 — Human-viewable DFD materialization

## Intent

Materialize a deterministic DFD semantic projection as a human-viewable artifact without transferring analysis semantics into the rendering layer.

## Functional obligation

- ThreatForge must provide at least one rendering adapter for a valid DFD semantic projection.
- The rendering adapter must produce a human-viewable DFD artifact.
- The rendered artifact must represent every projected node, directed data flow and boundary supplied by the semantic projection.
- The rendered artifact must preserve access to the traceability identities supplied by the semantic projection.
- The rendering adapter must not modify the DFD semantic projection.
- The rendering adapter must not modify canonical BAE or governed analysis records.
- Renderer-specific layout and presentation information must remain outside the DFD semantic projection.

## Scope

- Includes: at least one human-viewable DFD rendering adapter
- Includes: materialization of projected nodes
- Includes: materialization of directed data flows
- Includes: materialization of boundaries
- Includes: preservation of projection traceability
- Includes: separation between semantic projection and presentation
- Excludes: selection of multiple rendering formats
- Excludes: interactive DFD editing
- Excludes: method-specific analysis semantics
- Excludes: detailed DFD levels
- Excludes: manually governed diagram coordinates

## Acceptance

- The requirement is accepted when a valid DFD semantic projection produces a human-viewable artifact.
- The requirement is accepted when every projected node, directed data flow and boundary is represented in the artifact.
- The requirement is accepted when traceability identities carried by the semantic projection remain accessible from the artifact.
- The requirement is accepted when rendering leaves the DFD semantic projection unchanged.
- The requirement is accepted when rendering leaves canonical BAE and governed analysis records unchanged.
- The requirement is accepted when renderer-specific layout and presentation information is not written into the semantic projection.

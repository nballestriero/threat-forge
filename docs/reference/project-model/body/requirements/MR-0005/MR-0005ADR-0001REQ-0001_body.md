# MR-0005ADR-0001REQ-0001 — Governed methodology-specific analysis record boundary

## Intent

Provide the common governed input boundary between canonical Base Analysis knowledge and deterministic methodology-specific derivations.

## Functional obligation

- ThreatForge must represent expert-approved methodology-specific interpretations in governed analysis records separate from the canonical BAE registry.
- An analysis record that interprets a canonical BAE must retain an explicit reference to that BAE identity.
- Each methodology-specific analysis registry must identify the selected analysis method.
- Methodology-specific classifications must use controlled taxonomy values owned by the selected analysis method.
- Governed analysis records must expose whether they are accepted for deterministic derivation.
- Analysis record authoring must not modify canonical BAE records.

## Scope

- Includes: governed methodology-specific analysis records
- Includes: explicit references from analysis records to canonical BAE identities
- Includes: selected analysis method identity
- Includes: controlled methodology-specific taxonomy values
- Includes: acceptance state for deterministic derivation
- Excludes: method-specific threat classification rules
- Excludes: DFD projection structure and rendering
- Excludes: complete handling of Base Analysis discrepancies

## Acceptance

- The requirement is accepted when methodology-specific analysis records are stored separately from canonical BAE records.
- The requirement is accepted when every analysis interpretation of a canonical BAE resolves to an explicit BAE identity.
- The requirement is accepted when the selected method is identifiable for each methodology-specific analysis registry.
- The requirement is accepted when methodology-specific classifications resolve to controlled values owned by the selected method.
- The requirement is accepted when records accepted for deterministic derivation are distinguishable from records not accepted.
- The requirement is accepted when creating or updating analysis records leaves canonical BAE records unchanged.

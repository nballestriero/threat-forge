# MR-0005ADR-0001REQ-0002 — Deterministic DFD semantic projection

## Intent

Provide a methodology-independent semantic projection that converts accepted governed analysis records into a repeatable DFD model for downstream renderers.

## Functional obligation

- ThreatForge must derive the DFD semantic projection only from governed analysis records accepted for deterministic derivation.
- The DFD semantic projection must represent projected nodes, directed data flows and boundaries explicitly.
- Each projected DFD element must retain traceability to the governed analysis records that produced it.
- Projected elements originating from canonical BAEs must retain traceability to their BAE identities.
- Identical accepted analysis inputs must produce an identical DFD semantic projection.
- The DFD semantic projection must remain independent from renderer-specific layout and presentation data.
- Rendering adapters must consume the DFD semantic projection without redefining its analysis semantics.

## Scope

- Includes: methodology-independent DFD semantic projection
- Includes: projected nodes
- Includes: directed data flows
- Includes: boundaries
- Includes: traceability to governed analysis records
- Includes: traceability to canonical BAE identities
- Includes: deterministic projection output
- Excludes: STRIDE-specific projection rules
- Excludes: STRIDE-AI-specific projection rules
- Excludes: diagram coordinates and layout
- Excludes: renderer-specific styling
- Excludes: detailed DFD levels

## Acceptance

- The requirement is accepted when only analysis records accepted for deterministic derivation contribute to the DFD semantic projection.
- The requirement is accepted when projected nodes, directed data flows and boundaries are represented explicitly.
- The requirement is accepted when every projected DFD element resolves to its producing governed analysis records.
- The requirement is accepted when every projected element originating from a canonical BAE resolves to that BAE identity.
- The requirement is accepted when repeated projection of identical accepted inputs produces identical semantic output.
- The requirement is accepted when the semantic projection contains no renderer-specific coordinates or presentation styles.
- The requirement is accepted when a renderer can consume the projection without applying independent Base Analysis or methodology-specific rules.

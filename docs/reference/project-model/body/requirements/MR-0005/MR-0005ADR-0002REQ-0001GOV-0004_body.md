# MR-0005ADR-0002REQ-0001GOV-0004 — Deterministic Common Finding editor schema routing

## Intent

Activate deterministic Common Finding YAML editor assistance without requiring a per-file schema directive.

## Governance obligation

- The canonical ThreatForge workspace adapter must associate **/*.analysis-finding.yml with the current materialized Common Finding JSON Schema.
- A Target Project workspace that supports Common Finding authoring must expose the same engine-derived schema through a portable workspace-relative association.
- The routing must be generated or materialized from canonical schema metadata.
- The routing must not duplicate Common Finding model constraints.
- Editor routing must remain limited to structural YAML assistance.
- Editor routing must not replace repository validation of Analysis Record origins governed references or accepted-state Functional Requirement constraints.
- The routing materializers must modify only their declared VS Code workspace outputs.

## Verification obligations

- The verification must confirm that a Common Finding file receives schema assistance without a yaml-language-server directive.
- The verification must confirm completion and diagnostics for required fields identifier patterns affected-subject kinds and review states.
- The verification must confirm that missing stale duplicate or divergent Common Finding routing fails deterministically.
- The verification must confirm portable routing in the canonical ThreatForge workspace and supported Target Project workspaces.
- The verification must confirm that repository semantic validation remains separate and authoritative.

## Failure conditions

- The verification must fail when a Common Finding file requires a per-file schema directive to receive canonical editor assistance.
- The verification must fail when the workspace routes **/*.analysis-finding.yml to a missing stale or noncanonical schema.
- The verification must fail when the workspace adapter duplicates Common Finding model constraints.
- The verification must fail when a Target Project Common Finding route is not portable across engine and target roots.
- The verification must fail when editor routing is treated as proof of governed reference resolution or accepted-state semantic validity.

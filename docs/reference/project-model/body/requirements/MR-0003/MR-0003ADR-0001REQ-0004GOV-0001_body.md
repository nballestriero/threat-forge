# MR-0003ADR-0001REQ-0004GOV-0001 — Deterministic BAE change-impact evidence

## Intent

Ensure that lifecycle and staleness decisions are reproducible and supported by explicit dependency evidence.

## Governance obligation

- The change-impact validator must evaluate canonical provenance relations.
- The change-impact validator must evaluate canonical BAE dependency relations.
- The change-impact validator must evaluate analysis dependencies on BAE identities.
- The change-impact validator must produce deterministic affected-record ordering.
- The change-impact validator must preserve the triggering source identity.
- The change-impact validator must preserve every reported dependency path.
- The change-impact validator must not modify canonical BAE content.
- The change-impact validator must not modify canonical analysis content.
- A review resolution must identify one controlled outcome.
- A review resolution must preserve historical lifecycle evidence.

## Verification obligations

- The verification must compare repeated impact evaluations for deterministic equivalence.
- The verification must trace each affected analysis through at least one canonical BAE dependency path.
- The verification must confirm that impact evaluation leaves canonical sources unchanged.
- The verification must confirm that review resolution preserves previous lifecycle evidence.
- The verification must cover direct, transitive and unaffected dependency fixtures.
- The verification must cover missing-path, unknown-source and unauthorized-mutation negative fixtures.

## Failure conditions

- The verification must fail when an affected record lacks a dependency path.
- The verification must fail when the triggering source does not resolve.
- The verification must fail when identical input produces different affected-record ordering.
- The verification must fail when impact evaluation modifies canonical content.
- The verification must fail when a review outcome removes prior lifecycle evidence.

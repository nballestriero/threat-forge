# MR-0003ADR-0001REQ-0003GOV-0001 — Controlled BAE relation integrity

## Intent

Ensure that Base Analysis topology remains referentially valid and semantically controlled.

## Governance obligation

- The BAE relation validator must resolve every source endpoint.
- The BAE relation validator must resolve every target endpoint.
- The BAE relation validator must reject an unknown predicate.
- The BAE relation validator must reject an endpoint type that violates the predicate contract.
- The BAE relation validator must reject duplicate canonical relation records.
- The BAE relation validator must preserve base and overlay relation scopes.
- A topology projection must not contain an unregistered BAE node.
- A topology projection must not contain an unregistered BAE relation.
- An overlay mutation must not overwrite a canonical base relation.

## Verification obligations

- The verification must validate every relation against the controlled predicate catalog.
- The verification must validate endpoint types against the applicable predicate contract.
- The verification must compare projected topology with canonical BAE records and relations.
- The verification must confirm deterministic relation ordering for identical input.
- The verification must cover valid relations for every canonical BAE type.
- The verification must cover unknown endpoint, unknown predicate, invalid endpoint-type and duplicate-relation negative fixtures.

## Failure conditions

- The verification must fail when a relation endpoint does not resolve.
- The verification must fail when a relation predicate is unknown.
- The verification must fail when endpoint types violate the predicate contract.
- The verification must fail when a duplicate canonical relation exists.
- The verification must fail when an overlay overwrites a base relation.

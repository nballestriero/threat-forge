# MR-0003ADR-0001REQ-0001GOV-0001 — Deterministic BAE identity and record consistency

## Intent

Ensure that the canonical BAE inventory remains complete, unambiguous and reproducible.

## Governance obligation

- The BAE inventory validator must reject duplicate BAE identifiers.
- The BAE inventory validator must reject missing required record members.
- The BAE inventory validator must reject unknown canonical base types.
- The BAE inventory validator must reject an empty canonical title.
- The BAE inventory validator must reject an empty explicit meaning.
- The BAE inventory validator must reject an unresolvable governed origin.
- A canonical projection must preserve the registered BAE identifier.
- A canonical projection must preserve the registered canonical base type.
- A canonical projection must not introduce an unregistered BAE record.

## Verification obligations

- The verification must validate every BAE record against the canonical record contract.
- The verification must compare projected identifiers with the canonical inventory.
- The verification must compare projected base types with the canonical inventory.
- The verification must confirm deterministic ordered output for identical inventory input.
- The verification must cover every accepted canonical base type.
- The verification must cover duplicate, incomplete and unknown-type negative fixtures.

## Failure conditions

- The verification must fail when two BAE records use the same identifier.
- The verification must fail when a required BAE member is absent.
- The verification must fail when a BAE uses an unknown canonical base type.
- The verification must fail when a projection changes a canonical BAE identifier.
- The verification must fail when a projection introduces an unregistered BAE.

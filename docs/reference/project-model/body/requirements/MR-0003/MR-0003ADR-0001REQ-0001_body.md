# MR-0003ADR-0001REQ-0001 — Canonical Base Analysis Element inventory

## Intent

Provide one methodology-neutral inventory of stable system elements for Base Analysis.

## Functional obligation

- The Base Analysis capability must maintain one canonical BAE inventory for each analyzed project.
- Each BAE record must declare one stable governed identifier.
- Each BAE record must declare one canonical title.
- Each BAE record must declare one canonical base type.
- Each BAE record must declare an explicit meaning.
- Each BAE record must declare one lifecycle state.
- Each BAE record must declare one governed origin.
- Each BAE record must expose its documentary provenance.
- The canonical base type must be `Actor`, `Component`, `Data Resource`, `Boundary` or `Data Flow`.
- A project-specific refinement must preserve the canonical base identity.
- A project-specific refinement must preserve the canonical base type.
- A derived presentation must resolve BAE identity from the canonical inventory.
- A derived presentation must not create an independent BAE identity.

## Scope

- Includes: ThreatForge Base Analysis inventories
- Includes: child-project Base Analysis inventories
- Includes: stable BAE identity and canonical titles
- Includes: minimum methodology-neutral BAE types
- Includes: project-specific refinements
- Excludes: methodology-specific threat classifications
- Excludes: editor-specific presentation state
- Excludes: concrete storage technology

## Acceptance

- The requirement is accepted when one project inventory resolves every registered BAE by its stable identifier.
- The requirement is accepted when every BAE record contains title, base type, meaning, lifecycle state, origin and provenance.
- The requirement is accepted when the accepted base types are limited to the five values selected by ADR-0001.
- The requirement is accepted when two projections of the same inventory preserve identical BAE identifiers.
- The requirement is accepted when a project-specific refinement leaves the canonical base identity unchanged.

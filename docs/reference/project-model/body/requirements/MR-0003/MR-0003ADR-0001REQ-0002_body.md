# MR-0003ADR-0001REQ-0002 — Governed BAE origin and documentary provenance

## Intent

Preserve the governed knowledge and reviewed evidence that justify every Base Analysis Element.

## Functional obligation

- Each BAE must identify one governed origin.
- A governed origin must identify the source that justifies the existence of the BAE.
- A governed origin must be the originating document or a reviewed analytical addition.
- A reviewed analytical addition must identify its review evidence.
- BAE provenance must identify every governed source used to support the BAE.
- BAE provenance must distinguish the originating source from supporting sources.
- BAE provenance must preserve repository-relative source identity.
- A BAE reference must resolve to an existing canonical BAE record.
- A BAE reference must occur after or within its governed origin relation.
- A document must not reference a BAE introduced only by one of its descendants.
- The Base Analysis capability must not infer governed origin from the first textual occurrence of an identifier.
- The Base Analysis capability must expose the provenance chain for review.

## Scope

- Includes: Macro-requirement sources
- Includes: Decision sources
- Includes: Functional Requirement sources
- Includes: Governance Requirement sources
- Includes: reviewed analytical additions
- Includes: supporting evidence references
- Excludes: unreviewed LLM output
- Excludes: filesystem modification time as semantic origin
- Excludes: first textual occurrence as semantic origin

## Acceptance

- The requirement is accepted when every BAE resolves one governed origin.
- The requirement is accepted when a reviewed analytical addition resolves its review evidence.
- The requirement is accepted when originating and supporting sources remain distinguishable.
- The requirement is accepted when a document can reference a BAE introduced by that document.
- The requirement is accepted when a document can reference a BAE introduced by an ancestor or independent governed source.
- The requirement is accepted when a descendant-only origin is rejected.
- The requirement is accepted when the complete provenance chain is available for inspection.

# MR-0003ADR-0001REQ-0004 — BAE lifecycle change impact and analysis staleness

## Intent

Trace governed source changes to affected Base Analysis Elements and dependent analyses.

## Functional obligation

- Each BAE must expose one controlled lifecycle state.
- The Base Analysis capability must preserve the previous identity of a superseded BAE.
- The Base Analysis capability must preserve provenance for a deprecated BAE.
- The Base Analysis capability must compare governed source changes with recorded BAE provenance.
- The Base Analysis capability must identify BAE records affected by a changed source.
- The Base Analysis capability must identify analyses that depend on an affected BAE.
- The Base Analysis capability must report potentially stale BAE records.
- The Base Analysis capability must report potentially stale analyses.
- A staleness report must identify the triggering source change.
- A staleness report must identify every affected dependency path.
- A staleness report must not rewrite a BAE automatically.
- A staleness report must not rewrite an analysis automatically.
- A governed review must resolve each reported stale dependency.
- A governed review must record confirmation, update, supersession or deprecation as its outcome.

## Scope

- Includes: governed source changes
- Includes: BAE lifecycle transitions
- Includes: BAE dependency impact
- Includes: dependent-analysis impact
- Includes: review outcomes
- Excludes: silent automatic BAE rewriting
- Excludes: silent automatic analysis rewriting
- Excludes: methodology-specific risk scoring

## Acceptance

- The requirement is accepted when a changed provenance source identifies every directly affected BAE.
- The requirement is accepted when an affected BAE identifies every dependent analysis.
- The requirement is accepted when a staleness report contains the triggering change and dependency paths.
- The requirement is accepted when repeated evaluation of unchanged inputs reports no new impact.
- The requirement is accepted when review outcomes preserve prior governed identity and provenance.
- The requirement is accepted when staleness reporting leaves canonical BAE and analysis content unchanged.

# MR-0004ADR-0001REQ-0001 — Creazione del progetto target in una destinazione esplicita

## Intent

Enable a user or delivery adapter to create one governed target project at a chosen filesystem location without coupling project structure to the location of the ThreatForge engine.

## Functional obligation

- The target project creation capability must receive one explicit destination root for each creation request.
- The target project creation capability must validate the destination before writing target-owned artifacts.
- The target project creation capability must create the initial governed project structure relative to the validated destination root.
- The target project creation capability must produce the same initial governed structure for an internal demonstration destination and an external destination.
- The target project creation capability must not write target-owned artifacts into the canonical ThreatForge project-model paths.

## Scope

- Includes: explicit destination-root input
- Includes: validation before target creation
- Includes: initial governed project structure
- Includes: equivalent generation for internal and external destinations
- Includes: isolation from the canonical ThreatForge project model
- Excludes: opening an existing project through a target root
- Excludes: command-line syntax
- Excludes: backend API endpoints
- Excludes: web user-interface behavior
- Excludes: Base Analysis or threat-analysis execution
- Excludes: compatibility versions or migration behavior

## Acceptance

- The requirement is accepted when a valid internal destination produces a complete initial governed project rooted only at that destination.
- The requirement is accepted when a valid external destination produces the same governed structure as a valid internal destination.
- The requirement is accepted when an invalid or unusable destination is rejected before any target artifact is written.
- The requirement is accepted when target creation leaves the canonical ThreatForge project-model files unchanged.

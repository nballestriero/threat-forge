# MR-0001ADR-0007REQ-0001GOV-0001 — Wrapper sottili, naming canonico e dry-run sicuro

## Intento

Garantire che l'integrazione VS Code resti un punto di accesso sicuro e non diventi una seconda implementazione delle regole operative ThreatForge.

## Obbligo di governance

I task VS Code devono:

- usare esattamente label visibili con prefisso `ThreatForge:`;
- invocare i tool CLI esistenti tramite argomenti espliciti;
- usare la root del repository come directory di lavoro;
- mantenere `--dry-run` nei task che preparano documenti o handoff;
- non contenere logica di validazione, generazione o packaging duplicata;
- essere tracciati nel registro di implementation trace.

## Ambito

Incluso:

- naming delle label;
- mapping task-comando;
- directory di lavoro;
- modalità dry-run;
- tracciabilità dell'artefatto editor.

Escluso:

- validazione autonoma dei task tramite un nuovo checker;
- modifica dei tool CLI esistenti;
- automazione di commit o push dall'editor.

## Acceptance

Il requisito è soddisfatto quando il catalogo contiene solo wrapper dei comandi governati, usa le label canoniche previste e non esegue scritture nei task di authoring o handoff.

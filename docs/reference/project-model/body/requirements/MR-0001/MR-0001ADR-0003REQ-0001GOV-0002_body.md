# MR-0001ADR-0003REQ-0001GOV-0002 — Copertura negativa del controllo di tracciabilita implementativa

## Intent

Dimostrare che il controllo di tracciabilita implementativa intercetta esempi volutamente non validi, oltre a confermare il caso positivo del registro reale.

## Governance obligation

- The governed implementation must enforce this condition: Il controllo della tracciabilita implementativa deve eseguire fixture negative governate e deve fallire la verifica quando una fixture non produce gli errori attesi.

## Verification obligations

- The verification must confirm this condition: Il requisito copre fixture per registro mancante o malformato, artifact id assenti o duplicati, status e artifact_type non supportati, requisiti collegati mancanti o sconosciuti e sorgenti senza dichiarazione JSDoc coerente.
- The verification must confirm this condition: Il check passa solo quando tutte le fixture negative vengono eseguite, falliscono come previsto e producono i messaggi diagnostici attesi.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.
- The verification must fail when an invalid case passes without the expected stable diagnostic.

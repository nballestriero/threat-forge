# MR-0001ADR-0005REQ-0002 — Controllo degli header dei body governati

## Intento

La documentazione governata deve impedire che il titolo canonico dichiarato in un registro diverga dal titolo leggibile mostrato nel body Markdown.

## Obbligo funzionale

Il workspace deve fornire un controllo deterministico che legga i record governati dotati di `body_path`, apra i body Markdown collegati e verifichi la coerenza dell'H1 principale con `id` e `title` del record di registro.

## Ambito

Il controllo si applica inizialmente ai macro-requirement, alle decisioni ADR e ai requisiti funzionali o governance presenti nel Project Model locale.

## Acceptance

Il requisito e soddisfatto quando il controllo segnala errore per body mancanti, H1 mancanti, H1 multipli, `title` mancanti o header non corrispondenti alla forma canonica `# <id> — <title>`.

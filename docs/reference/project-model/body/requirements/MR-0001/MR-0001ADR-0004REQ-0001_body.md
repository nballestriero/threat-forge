# MR-0001ADR-0004REQ-0001 — Registro dei valori controllati dei campi documentali

## Intent

Provide contextual and machine-readable definitions for controlled values used by governed document fields and registries.

## Functional obligation

- The Project Model must maintain one governed taxonomy registry containing contextual value sets for controlled document fields.
- Each value set must identify its canonical field, applicable registry, applicable record type, allowed values and the meaning of every value.
- Status fields must use context-specific value sets instead of one ambiguous global status taxonomy.
- The registry must distinguish concrete Requirement types from abstract or non-persistable Requirement categories.
- The registry must represent controlled result values and temporary phrases forbidden in governed documentation when those controls are defined.
- New controlled fields must be added through governed value-set records rather than through duplicated enum definitions.

## Scope

- Includes: vocabulary label roles and vocabulary lifecycle values
- Includes: check, artifact, Decision and Requirement lifecycle values
- Includes: concrete Requirement type values and parent rules
- Includes: execution report result values
- Includes: governed forbidden temporary phrases
- Excludes: an exhaustive definition of every future controlled field
- Excludes: the complete derived implementation-state model for Requirements

## Acceptance

- The requirement is accepted when every governed controlled field in scope references one contextual value set.
- The requirement is accepted when every allowed value has a deterministic meaning.
- The requirement is accepted when identical status labels with different semantics belong to different contextual value sets.
- The requirement is accepted when abstract or forbidden Requirement categories cannot be persisted as concrete `requirement_type` values.
- The requirement is accepted when deterministic checks can validate consuming registries against the taxonomy registry.

# MR-0001ADR-0004REQ-0001 — Registro dei valori controllati dei campi documentali

## Intento

La documentazione governata deve mantenere un registro dei valori controllati usati dai campi documentali e dai registri.

## Obbligo funzionale

Il modello documentale deve includere un registro tassonomico che dichiara value set contestuali per i campi controllati.

Ogni value set deve dichiarare il campo, il registro a cui si applica, il tipo di record a cui si applica, i valori ammessi e il significato di ciascun valore.

## Ambito iniziale

Il primo ambito include almeno:

- ruoli delle label del vocabolario controllato;
- status del registry dei value set;
- status del registry vocabolario;
- status dei termini del vocabolario;
- status dei controlli locali;
- status degli artefatti implementativi;
- status delle decisioni;
- lifecycle status dei requirement;
- tipi concreti ammessi nel campo `requirement_type` e relative regole di parentela;
- result status dei report di esecuzione;
- frasi temporanee vietate nella documentazione governata.

## Regola sul campo status

Non deve esistere una tassonomia globale generica per `status` quando lo stesso valore può avere significati diversi in registri diversi.

I valori di status devono essere definiti tramite value set contestuali, per esempio `check_status`, `implementation_artifact_status`, `decision_status`, `requirement_lifecycle_status` e `vocabulary_term_status`.

## Esclusioni

Il requisito non decide ancora l'elenco completo di tutti i campi controllati futuri. Nuovi campi possono essere aggiunti con record tassonomici successivi.

Il requisito non decide ancora il modello completo di implementation state derivato dai requirement.

## Verificabilità

Il requisito è verificabile tramite un controllo deterministico che legge il registro tassonomico e gli altri registri governati che consumano quei valori.

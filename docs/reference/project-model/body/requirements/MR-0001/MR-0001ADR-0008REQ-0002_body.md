# MR-0001ADR-0008REQ-0002 — Deterministic governed entity reference resolution

## Intent

Resolve each canonical reference against authoritative governed sources and entity-owned eligibility rules.

## Functional obligation

- The governed reference resolver must accept the current document identity.
- The governed reference resolver must accept the applicable body profile.
- The governed reference resolver must accept the reference-bearing position.
- The governed reference resolver must accept the parsed canonical identifier.
- The governed reference resolver must accept the authored title.
- The applicable body profile must declare the allowed governed entity types.
- The governed reference resolver must identify the registered resolver for the referenced entity type.
- The governed reference resolver must resolve exactly one authoritative entity record.
- The governed reference resolver must not infer entity semantics from editor-owned rules.
- The governed reference resolver must verify that the resolved entity type is allowed in the current position.
- The governed reference resolver must compare the authored title with the canonical title.
- A title mismatch must produce a deterministic diagnostic.
- A title mismatch must expose the canonical replacement payload.
- A title mismatch must not rewrite the authored document silently.
- The governed reference resolver must evaluate eligibility through the entity-owning model.
- The governed reference resolver must reject an unknown, ambiguous, disallowed or ineligible entity.
- The governed reference resolver must preserve the authoritative source identity.
- A resolved reference must not create or originate the referenced entity.
- Repeated resolution of identical canonical inputs must produce equivalent ordered results.

## Scope

- Includes: registered referenceable governed entity types
- Includes: canonical source resolution
- Includes: body-profile type restrictions
- Includes: canonical title comparison
- Includes: entity-owned reference eligibility
- Includes: BAE origin and precedence eligibility from MR-0003
- Excludes: external URL resolution
- Excludes: entity creation or origin assignment
- Excludes: silent document mutation
- Excludes: editor-specific rendering

## Acceptance

- The requirement is accepted when a canonical BAE reference resolves one registered BAE record.
- The requirement is accepted when the resolved entity type is permitted by the applicable body profile.
- The requirement is accepted when an unknown identifier produces an invalid reference result.
- The requirement is accepted when an ambiguous identifier produces an invalid reference result.
- The requirement is accepted when a disallowed entity type produces an invalid reference result.
- The requirement is accepted when a divergent title produces a canonical replacement payload without modifying the document.
- The requirement is accepted when a BAE with a descendant-only origin produces an ineligible reference result.
- The requirement is accepted when identical resolution input produces equivalent ordered results.

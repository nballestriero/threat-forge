# MR-0001ADR-0004REQ-0002GOV-0002 — Freshness deterministica delle proiezioni dei campi controllati

## Intent

Garantire che ogni proiezione consumata da editor, tool, API o frontend rimanga sincronizzata con le fonti canoniche dei campi controllati.

## Governance obligation

- The governed implementation must enforce this condition: Le proiezioni generate dal catalogo dei campi controllati devono essere deterministiche, revisionabili e verificabili rispetto allo snapshot corrente delle fonti canoniche.
- The governed implementation must enforce this condition: produrre una modifica deterministica delle proiezioni interessate; oppure.
- The governed implementation must enforce this condition: rendere il controllo di freshness non superato fino alla rigenerazione.
- The governed implementation must enforce this condition: I controlli non devono aggiornare silenziosamente gli artefatti durante la verifica.

## Verification obligations

- The verification must confirm this condition: valore concreto selezionabile accettato.
- The verification must confirm this condition: valore astratto o vietato respinto.
- The verification must confirm this condition: alias ammesso risolto secondo la fonte canonica.
- The verification must confirm this condition: alias assente o vietato respinto.
- The verification must confirm this condition: valore senza label o descrizione respinto quando selezionabile.
- The verification must confirm this condition: proiezione stale rilevata.
- The verification must confirm this condition: provenienza mancante o ambigua rilevata.
- The verification must confirm this condition: determinismo a parita di snapshot canonico.
- The verification must confirm this condition: assenza di mutazioni durante la modalita di controllo.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

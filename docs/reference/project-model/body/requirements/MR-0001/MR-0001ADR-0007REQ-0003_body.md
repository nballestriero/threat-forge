# MR-0001ADR-0007REQ-0003 — Governed migration of the active document corpus

## Intent

Bring every active governed registry record and referenced Markdown body into the canonical document models before blocking enforcement.

## Functional obligation

- The migration must inventory governed documents from canonical registry references.
- The migration must produce a read-only report before modifying any document.
- The migration must group findings by logical model, representation and rule identifier.
- The migration must preserve the semantic intent of every migrated decision and requirement.
- The migration must apply deterministic structural transformations automatically when semantics are unchanged.
- The migration must require reviewed edits when a transformation changes normative meaning.
- The migration must execute by complete document category.
- The migration must not retain a legacy compatibility mode after activation.

## Scope

- Includes: active Macro-requirement records and bodies
- Includes: active Decision records and bodies
- Includes: active Functional Requirement records and bodies
- Includes: active Governance Requirement records and bodies
- Excludes: unreferenced Markdown files
- Excludes: archived legacy trees

## Acceptance

- The requirement is accepted when every active registry record conforms to its canonical profile.
- The requirement is accepted when every referenced body conforms to its canonical profile.
- The requirement is accepted when every mirrored field and cross-model relation is coherent.
- The requirement is accepted when the complete migration report contains zero errors.

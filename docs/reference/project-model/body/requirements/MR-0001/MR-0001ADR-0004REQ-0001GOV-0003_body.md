# MR-0001ADR-0004REQ-0001GOV-0003 — Concretezza e regole dei tipi di requisito

## Intent

Impedire che una categoria astratta venga memorizzata come tipo concreto e rendere derivabili le regole di parentela applicabili a ogni requisito governato.

## Governance obligation

- The governed implementation must enforce this condition: Il registro dei valori controllati deve definire un value set contestuale denominato `requirement_type` per il campo omonimo dei registri dei requisiti.
- The governed implementation must enforce this condition: `value`.
- The governed implementation must enforce this condition: `meaning`.
- The governed implementation must enforce this condition: `is_specialized`.
- The governed implementation must enforce this condition: `requires_parent_requirement`.
- The governed implementation must enforce this condition: `allowed_parent_requirement_types`.
- The governed implementation must enforce this condition: `specialized` e una categoria astratta e non deve comparire tra i valori ammessi di `requirement_type`.
- The governed implementation must enforce this condition: `functional`, non specializzato, senza requisito padre.
- The governed implementation must enforce this condition: `governance`, specializzato, con requisito padre obbligatorio di tipo `functional`.
- The governed implementation must enforce this condition: Ogni estensione deve introdurre un tipo concreto distinto, con significato e regole applicabili esplicite. Un tipo concreto non deve essere introdotto come alias implicito di un altro tipo.

## Verification obligations

- The verification must confirm this condition: presenza del value set `requirement_type`.
- The verification must confirm this condition: unicita dei tipi concreti.
- The verification must confirm this condition: assenza del valore `specialized`.
- The verification must confirm this condition: presenza e tipo booleano di `is_specialized` e `requires_parent_requirement`.
- The verification must confirm this condition: presenza di `allowed_parent_requirement_types`.
- The verification must confirm this condition: lista dei tipi padre vuota quando il padre non e richiesto.
- The verification must confirm this condition: lista dei tipi padre non vuota e composta da tipi concreti registrati quando il padre e richiesto.
- The verification must confirm this condition: uso nei registri dei requisiti di soli tipi concreti registrati.
- The verification must confirm this condition: presenza o assenza di `parent_requirement_id` coerente con le regole del tipo concreto.
- The verification must confirm this condition: tipo del requisito padre compreso tra quelli ammessi.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

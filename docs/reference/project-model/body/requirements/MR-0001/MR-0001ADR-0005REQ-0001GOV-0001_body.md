# MR-0001ADR-0005REQ-0001GOV-0001 — Coerenza deterministica tra record di registro e body generati

## Intento

Il generatore non deve introdurre incoerenza tra registry e body Markdown.

## Obbligo di governance

Ogni documento governato generato deve usare il registro come fonte canonica per `id`, `title`, `status`, `requirement_type`, relazioni e `body_path`.

Il body generato deve includere un H1 derivato dall'identificativo e dal titolo generati per il record del registro.

## Controlli minimi

Il generatore deve almeno:

- impedire la sovrascrittura di body esistenti;
- impedire la duplicazione di id gia presenti nel registro;
- derivare il prossimo id dal contesto MR/ADR o dal requisito padre;
- creare un path coerente con l'id generato;
- supportare una modalita dry-run senza side effect;
- produrre un body con H1 leggibile e coerente.

## Failure mode

Il generatore deve fallire senza scrivere file quando mancano input obbligatori, quando il registro target non esiste, quando il requisito padre non esiste o quando il body da creare esiste gia.

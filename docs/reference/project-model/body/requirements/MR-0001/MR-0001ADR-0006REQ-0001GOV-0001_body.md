# MR-0001ADR-0006REQ-0001GOV-0001 — Produzione locale deterministica dell'handoff archive

## Intent

Garantire che l'handoff archive sia prodotto in modo locale, ripetibile e coerente con lo stato governato del repository.

## Governance obligation

- The governed implementation must enforce this condition: essere eseguito dal repository locale.
- The governed implementation must enforce this condition: usare `ThreatForge` come label visibile.
- The governed implementation must enforce this condition: non usare `Restart` come label utente.
- The governed implementation must enforce this condition: includere stato Git, log, registry snapshot e output del check locale.
- The governed implementation must enforce this condition: fallire in modalità non dry-run quando il working tree non è pulito, salvo opzione esplicita di override.
- The governed implementation must enforce this condition: dichiarare il requisito implementato tramite JSDoc.

## Verification obligations

- The verification must confirm this condition: generazione archive.
- The verification must confirm this condition: controllo working tree.
- The verification must confirm this condition: contenuto di continuità.
- The verification must confirm this condition: tracciabilità implementativa.
- The verification must confirm this condition: validazione semantica completa dei contenuti inclusi.
- The verification must confirm this condition: pubblicazione remota dell'archive.
- The verification must confirm this condition: Il requisito è soddisfatto quando il tool è presente, tracciato, verificabile con `--dry-run` e produce localmente un archive deterministico dopo commit/push governato.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

# MR-0001ADR-0003REQ-0001GOV-0001 — Coerenza deterministica tra registro, requisiti e codice

## Intent

Il registro di tracciabilita implementativa e utile solo se rimane sincronizzato con i requisiti e con il codice. Questo requisito specializzato trasforma il registro in una fonte controllabile: gli artefatti pianificati diventano warning visibili, mentre gli artefatti dichiarati implementati devono essere verificabili.

## Governance obligation

- The governed implementation must enforce this condition: Il registro di tracciabilita implementativa deve essere controllabile deterministicamente contro i registri requisiti e contro gli artefatti implementativi presenti nel repository.
- The governed implementation must enforce this condition: ogni requisito collegato dal registro esiste in un registro requisiti.
- The governed implementation must enforce this condition: ogni record ha uno stato ammesso.
- The governed implementation must enforce this condition: ogni artefatto pianificato puo mancare dal repository senza bloccare il controllo.
- The governed implementation must enforce this condition: ogni artefatto pianificato non implementato produce un warning deterministico.
- The governed implementation must enforce this condition: ogni artefatto dichiarato implementato esiste al percorso dichiarato.
- The governed implementation must enforce this condition: ogni artefatto implementato dichiara nel codice i requisiti che implementa o supporta.
- The governed implementation must enforce this condition: il codice non dichiara requisiti inesistenti.
- The governed implementation must enforce this condition: il registro e il codice non divergono sui requisiti collegati.
- The governed implementation must enforce this condition: Il controllo puo essere realizzato da un singolo tool o da piu tool coordinati da un orchestratore.

## Verification obligations

- The verification must confirm this condition: fallire se il registro cita un requisito inesistente.
- The verification must confirm this condition: emettere warning se un artefatto pianificato non e ancora presente.
- The verification must confirm this condition: fallire se un artefatto dichiarato implementato non esiste.
- The verification must confirm this condition: fallire se un artefatto implementato non dichiara i requisiti collegati.
- The verification must confirm this condition: fallire se il codice dichiara requisiti inesistenti.
- The verification must confirm this condition: produrre un report leggibile delle incoerenze rilevate.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.
- The verification must fail when an invalid case passes without the expected stable diagnostic.

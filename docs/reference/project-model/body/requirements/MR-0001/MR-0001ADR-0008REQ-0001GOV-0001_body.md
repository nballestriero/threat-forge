# MR-0001ADR-0008REQ-0001GOV-0001 — Single reference grammar and source-derived labels

## Intent

Ensure that every governed document model consumes one canonical reference grammar and authoritative entity labels.

## Governance obligation

- The governed reference grammar contract must be the single source for payload structure.
- A reference-bearing body profile must reference the shared grammar contract.
- A reference-bearing body profile must not duplicate the canonical payload grammar.
- The reference parser must derive accepted structure from the canonical grammar contract.
- The reference serializer must derive emitted structure from the canonical grammar contract.
- Canonical title projection must come from the authoritative entity source.
- A compatibility layer must not accept an alternative governed reference form.
- A generated reference projection must remain current with its canonical sources.
- A canonical reference parser must produce deterministic values for identical input.
- A canonical reference serializer must produce deterministic text for identical resolved input.

## Verification obligations

- The verification must compare every reference-bearing profile with the shared grammar contract.
- The verification must compare serialized titles with authoritative entity titles.
- The verification must confirm deterministic parse results for identical payloads.
- The verification must confirm deterministic serialization for identical resolved input.
- The verification must cover canonical payloads with every registered referenceable entity type.
- The verification must cover parenthesized, bare, linked, whitespace-divergent and title-divergent negative fixtures.
- The verification must confirm that parsing and serialization leave canonical sources unchanged.

## Failure conditions

- The verification must fail when a body profile embeds an independent payload grammar.
- The verification must fail when an alternative payload form is accepted as canonical.
- The verification must fail when a serialized title differs from the authoritative entity title.
- The verification must fail when identical payload input produces different parsed values.
- The verification must fail when identical resolved input produces different serialized text.
- The verification must fail when reference processing modifies an authoritative entity source.

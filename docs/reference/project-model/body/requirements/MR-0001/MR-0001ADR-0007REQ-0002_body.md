# MR-0001ADR-0007REQ-0002 — Model-oriented validation of governed documents

## Intent

Validate each governed document as one logical model instead of as unrelated registry and body fragments.

## Functional obligation

- ThreatForge must provide one validation entrypoint for every active governed document model declared by the canonical document model index.
- Every active governed document model must have exactly one discoverable complete-model validation provider.
- ThreatForge must provide one validation entrypoint for cross-model relational coherence.
- Each model validator must validate registry structure, body structure, controlled values, mirrored fields and model relations.
- Each model validator must return deterministic diagnostics with stable rule identifiers.

## Scope

- Includes: complete-model repository checks
- Includes: registry and Markdown representation validation
- Includes: cross-model identity, path and parent relations
- Excludes: implementation trace validation
- Excludes: repository Git operation validation

## Acceptance

- The requirement is accepted when each logical model has one discoverable validation entrypoint.
- The requirement is accepted when cross-model relations have one discoverable validation entrypoint.
- The requirement is accepted when diagnostics identify rule, model, representation, file and location.
- The requirement is accepted when equivalent input produces equivalent ordered diagnostics.

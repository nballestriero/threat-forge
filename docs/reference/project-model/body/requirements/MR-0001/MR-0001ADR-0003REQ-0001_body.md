# MR-0001ADR-0003REQ-0001 — Registro di tracciabilita implementativa

## Intent

Provide a deterministic source that connects governed Requirements with planned or implemented artifacts, repository paths and verification evidence.

## Functional obligation

- ThreatForge must maintain one governed implementation trace registry for artifacts linked to governed Requirements.
- The registry must represent both planned artifacts and implemented artifacts.
- Each planned artifact record must declare a governed identifier, artifact type, status, linked Requirements, planned path, reason and completion condition.
- Each implemented artifact record must declare a governed identifier, artifact type, status, linked Requirements, implemented path and an applicable verification command.
- The registry must support deterministic traversal from each Requirement to its artifacts and from each artifact to its linked Requirements.
- The registry must keep documentation lifecycle state separate from implementation artifact state.

## Scope

- Includes: tools, reports, gates, fixtures and verification artifacts
- Includes: planned, scaffolded and implemented artifact records
- Includes: repository paths and verification commands
- Excludes: replacement of the Requirement registries
- Excludes: replacement of source code as the implementation authority
- Excludes: automatic evaluation of functional code quality

## Acceptance

- The requirement is accepted when the implementation trace registry is deterministically readable.
- The requirement is accepted when every artifact record has a governed identifier, type, status and at least one linked Requirement.
- The requirement is accepted when every planned artifact declares a planned path and completion condition.
- The requirement is accepted when every implemented artifact declares an implemented path.
- The requirement is accepted when deterministic checks can resolve artifact coverage without reading Requirement body prose.
- The requirement is accepted when planned artifacts remain distinguishable from artifacts that exist in the repository.

# MR-0001ADR-0007REQ-0002GOV-0002 — Absorption of overlapping partial document checks

## Intent

Prevent duplicate gates from validating the same governed document concern through independent logic.

## Governance obligation

- A model validator must absorb existing partial checks that govern the same document representation or relation.
- An existing partial check must not be removed before replacement coverage is proven.
- The local check registry must expose one active entrypoint for each complete document model after migration.
- The local check registry must expose one active entrypoint for cross-model coherence after migration.
- A retired partial checker must not remain an independently active gate.

## Verification obligations

- The verification must map every retired partial rule to an equivalent or stronger model rule.
- The verification must compare positive and negative coverage before a partial checker is retired.
- The verification must confirm that the local check registry does not execute overlapping document gates.
- The verification must preserve traceability from replacement checks to governed requirements.

## Failure conditions

- The verification must fail when a partial checker is removed without mapped replacement rules.
- The verification must fail when two active checks independently own the same canonical rule.
- The verification must fail when replacement coverage is weaker than the retired check coverage.
- The verification must fail when an active check has no governed requirement trace.

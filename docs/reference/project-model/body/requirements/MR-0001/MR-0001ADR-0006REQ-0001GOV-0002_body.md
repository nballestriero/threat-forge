# MR-0001ADR-0006REQ-0001GOV-0002 — Snapshot completo del progetto per continuita LLM

## Intent

Garantire che l'handoff archive sia sufficiente per permettere a un LLM di leggere il progetto e riprendere lo sviluppo senza dipendere solo da un riassunto di chat.

## Governance obligation

- The governed implementation must enforce this condition: Il tool di handoff deve includere nello ZIP uno snapshot completo del progetto operativo ThreatForge basato sui file tracciati da Git e filtrato rispetto al materiale legacy di sola consultazione.
- The governed implementation must enforce this condition: essere collocato sotto `project-snapshot/`.
- The governed implementation must enforce this condition: preservare i path relativi dei file tracciati.
- The governed implementation must enforce this condition: includere documentazione, registri, tool e configurazioni tracciate del progetto operativo.
- The governed implementation must enforce this condition: includere un manifest leggibile con HEAD, branch, conteggio file e regole di inclusione.
- The governed implementation must enforce this condition: escludere `.git`, `old/`, dipendenze installate, cache, build output e artifact non tracciati.

## Verification obligations

- The verification must confirm this condition: snapshot dei file ritornati da `git ls-files` che non ricadono sotto `old/`.
- The verification must confirm this condition: manifest dello snapshot.
- The verification must confirm this condition: struttura adatta alla lettura da parte di un LLM.
- The verification must confirm this condition: copia del materiale legacy archiviato sotto `old/`.
- The verification must confirm this condition: copia di file ignorati o non tracciati.
- The verification must confirm this condition: copia di segreti non tracciati.
- The verification must confirm this condition: esportazione di repository remoti.
- The verification must confirm this condition: compressione semantica o sintesi automatica del codice.
- The verification must confirm this condition: Il requisito è soddisfatto quando l'archive generato contiene `project-snapshot/` con tutti i file tracciati del progetto operativo, nessun file sotto `old/` e un manifest che descrive esplicitamente la regola di esclusione.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

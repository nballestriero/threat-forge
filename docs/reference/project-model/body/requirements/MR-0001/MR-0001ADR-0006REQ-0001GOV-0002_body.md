# MR-0001ADR-0006REQ-0001GOV-0002 — Snapshot completo del progetto per continuita LLM

## Intento

Garantire che l'handoff archive sia sufficiente per permettere a un LLM di leggere il progetto e riprendere lo sviluppo senza dipendere solo da un riassunto di chat.

## Obbligo di governance

Il tool di handoff deve includere nello ZIP uno snapshot completo del progetto operativo ThreatForge basato sui file tracciati da Git e filtrato rispetto al materiale legacy di sola consultazione.

Lo snapshot deve:

- essere collocato sotto `project-snapshot/`;
- preservare i path relativi dei file tracciati;
- includere documentazione, registri, tool e configurazioni tracciate del progetto operativo;
- includere un manifest leggibile con HEAD, branch, conteggio file e regole di inclusione;
- escludere `.git`, `old/`, dipendenze installate, cache, build output e artifact non tracciati.

## Ambito

Incluso:

- snapshot dei file ritornati da `git ls-files` che non ricadono sotto `old/`;
- manifest dello snapshot;
- struttura adatta alla lettura da parte di un LLM.

Escluso:

- copia del materiale legacy archiviato sotto `old/`;
- copia di file ignorati o non tracciati;
- copia di segreti non tracciati;
- esportazione di repository remoti;
- compressione semantica o sintesi automatica del codice.

## Acceptance

Il requisito è soddisfatto quando l'archive generato contiene `project-snapshot/` con tutti i file tracciati del progetto operativo, nessun file sotto `old/` e un manifest che descrive esplicitamente la regola di esclusione.

# MR-0001ADR-0004REQ-0002GOV-0001 — Provenienza canonica obbligatoria e divieto di duplicazione

## Intent

Impedire che tool, schema, task, API o componenti frontend mantengano copie locali divergenti dei valori controllati, degli alias o dei metadati di presentazione.

## Governance obligation

- The governed implementation must enforce this condition: Ogni input o output controllato deve dichiarare la fonte canonica da cui derivano valori, significati, label, selezionabilita, alias e metadati di presentazione.
- The governed implementation must enforce this condition: enum locali di valori controllati.
- The governed implementation must enforce this condition: alias non dichiarati dalla fonte canonica.
- The governed implementation must enforce this condition: significati o descrizioni sostitutive.
- The governed implementation must enforce this condition: colori con significato di dominio duplicato.
- The governed implementation must enforce this condition: regole di applicabilita ricostruite indipendentemente dal catalogo.
- The governed implementation must enforce this condition: conversioni che trasformano un valore astratto o vietato in un valore concreto accettabile.
- The governed implementation must enforce this condition: Sono ammessi valori non validi soltanto in fixture negative isolate e chiaramente identificate come casi di errore.

## Verification obligations

- The verification must confirm this condition: che ogni campo controllato consumato da un artefatto dichiari la propria fonte.
- The verification must confirm this condition: che ogni valore operativo provenga dal catalogo o dalla fonte canonica dichiarata.
- The verification must confirm this condition: che gli alias accettati siano registrati esplicitamente.
- The verification must confirm this condition: che valori astratti, vietati o non memorizzabili vengano respinti prima di qualsiasi scrittura.
- The verification must confirm this condition: che schema, cataloghi derivati, API e frontend non ridefiniscano descrizioni o valori.
- The verification must confirm this condition: che il body Markdown non venga trattato come fonte autonoma dei campi strutturati.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.

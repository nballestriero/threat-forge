# MR-0001ADR-0004REQ-0001GOV-0001 — Coerenza deterministica dei valori tassonomici documentali

## Intent

I valori controllati non devono essere stringhe libere o sinonimi impliciti.

## Governance obligation

- The governed implementation must enforce this condition: Ogni valore controllato usato dai registri coperti dal modello tassonomico deve essere presente nel value set applicabile e deve avere un significato esplicito.
- The governed implementation must enforce this condition: I value set devono essere contestuali. In particolare, il campo `status` non deve essere validato contro una lista globale unica, ma contro il value set specifico del registro e del tipo di record in cui compare.

## Verification obligations

- The verification must confirm this condition: unicità degli id dei value set.
- The verification must confirm this condition: unicità dei nomi dei value set.
- The verification must confirm this condition: presenza di `field_name`.
- The verification must confirm this condition: presenza di `applies_to_registry`.
- The verification must confirm this condition: presenza di `applies_to_record`.
- The verification must confirm this condition: presenza di descrizione per ogni value set.
- The verification must confirm this condition: presenza di significato per ogni valore ammesso.
- The verification must confirm this condition: coerenza tra i ruoli delle label usati nel vocabolario e il value set `vocabulary_label_role`.
- The verification must confirm this condition: coerenza tra gli status dei termini e il value set `vocabulary_term_status`.
- The verification must confirm this condition: coerenza tra gli status dei check e il value set `check_status`.
- The verification must confirm this condition: coerenza tra gli status degli artefatti implementativi e il value set `implementation_artifact_status`.
- The verification must confirm this condition: coerenza tra gli status delle decisioni e il value set `decision_status`.
- The verification must confirm this condition: coerenza tra gli status dei requirement e il value set `requirement_lifecycle_status`.
- The verification must confirm this condition: assenza di frasi operative temporanee vietate nei documenti governati non dedicati alla loro dichiarazione.

## Failure conditions

- The verification must fail when any governed obligation is violated or required deterministic evidence is missing.
- The verification must fail when an invalid case passes without the expected stable diagnostic.

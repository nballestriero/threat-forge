# MR-0001ADR-0001REQ-0001 — Describe the demonstration interaction

## Intent

Represent one small service interaction as governed documentary evidence suitable for Base Analysis and future implementation.

## Functional obligation

- The project documentation must describe one directed request from the demonstration user to the demonstration service.

## Scope

- Includes: [BAE-0001] Demonstration user
- Includes: [BAE-0002] Demonstration service
- Includes: [BAE-0003] Demonstration record
- Includes: [BAE-0004] Service domain boundary
- Includes: [BAE-0005] Demonstration request flow
- Excludes: Concrete executable source code
- Excludes: Technology-specific implementation choices

## Acceptance

- The requirement is accepted when the actor, component, data resource, boundary and data flow are represented in the project-local Base Analysis inventory with canonical endpoint and boundary relations.

# Document Before Code

Use this child project by adding or updating governed documentation before adding implementation code.

1. Add or update an ADR under `docs/reference/project-model/registers/decisions/`.
2. Add or update requirements under `docs/reference/project-model/registers/requirements/`.
3. Add Markdown bodies under `docs/reference/project-model/body/`.
4. Connect the work in the graph under `docs/reference/project-model/registers/graph/`.
5. Only then add implementation artifacts with traceability to requirements.

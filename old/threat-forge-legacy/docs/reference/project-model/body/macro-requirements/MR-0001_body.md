# MR-0001: Governed documentation and traceability

## Purpose

Questo macrorequisito funzionale governa la struttura documentale, la tracciabilità dei requisiti, le decisioni ADR, i grafi SPO e i controlli deterministici del project model.

## Scope

Include:

- registri documentali del project model;
- requisiti governati e loro riferimenti;
- decisioni ADR e relativi body file;
- grafi SPO, nodi e predicate;
- tassonomie condivise necessarie alla governance;
- pagine HTML generate per studio, revisione e analisi.

## Out of Scope

Non include:

- logica applicativa backend del prodotto finale;
- UI finale del prodotto;
- runtime di threat analysis;
- integrazioni AI runtime.

## Governance Notes

`MR-0001` è sia il macrorequisito funzionale sia il contenitore logico dell'area. Non esiste un `AREA-0001` separato: i registri e i grafi collegati a questo dominio usano direttamente `macro_requirement_id: MR-0001`.
